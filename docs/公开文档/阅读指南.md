# NEH 文档导航

Nuwax Embodied Harness（NEH，具身运行框架）面向将不同机器人接入统一空间能力的开发者。文档对应所在代码分支；第一次下载请先确认[版本与支持范围](发布与兼容性.md)。

## 第一次使用

按顺序完成：**准备电脑 → 安装模块 → 打开控制台 → 接入数据 → 验证功能 → 连接智能体**。

| [安装前准备](安装前准备.md) | 系统、解释器、仓库权限、下载渠道和硬件条件 |
| [快速上手](快速上手.md) | 从下载源码到第一次看到接口与控制台 |
| [安装与部署](部署文档.md) | 安装方案、模块、参数、Go2 更新及生产服务边界 |
| [配置说明](配置说明.md) | 初始配置、机器人方案、地址端口与生效范围 |
| [控制台使用指南](控制台使用指南.md) | 地图、视频、任务、日志和设置如何配合使用 |
