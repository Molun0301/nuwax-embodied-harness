# NEH 文档导航

Nuwax Embodied Harness（NEH，具身运行框架）把不同机器人接入同一套空间能力：建图、定位、导航、探索、视觉感知和空间记忆，再通过 MCP（模型上下文协议）或 HTTP（超文本传输协议）接口交给上层智能体使用。文档对应所在代码分支；第一次使用先看[发布与兼容性](发布与兼容性.md)确认支持范围。

## 第一次使用

按顺序完成：**安装 → 打开管理页与控制台 → 接入设备数据 → 验证功能 → 连接智能体**。
