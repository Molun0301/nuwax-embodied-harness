# 快速上手

本指南带你安装 Nuwax Embodied Harness（NEH，具身运行框架）、打开控制台，并逐步接入自己的机器人。第一次先完成基础软件与标准输入，再按设备条件增加建图和运动能力。

## 0. 运行唯一安装命令

在目标设备终端，复制并执行[安装说明中的完整命令](轻量安装与自动发布.md#一条命令安装并打开网页)。不需要先下载脚本或选择发行包。

当前测试期按提示完成GitHub登录；随后自动下载管理程序、安装服务并打开网页。设备要求管理员密码时按终端提示输入。有桌面环境直接进入管理页；无桌面设备会打印网页地址，在电脑浏览器中打开即可。

## 1. 选择机器人与模块

在管理页查看系统、架构和解释器的探测结果，选择机器人和所需模块。首次可选择基础网关；二维建图、FastLIO2（快速激光惯性里程计）和PointLIO（逐点激光惯性里程计）可以共同安装，需要导航时同时选择导航模块。

管理器取得源码分支的固定提交，页面显示系统依赖、缺项与操作步骤，确认后在设备构建所选模块。当前运行的建图链路和定位后端由机器人配置选择。

源码、依赖和模型按需下载；更新复用已有依赖环境及原生构建缓存。安装完成后通过管理页进入业务控制台。

## 2. 配置并连接设备

在管理页设置机器人、设备地址、接口、传感器和标定。网页和命令行使用同一配置拥有方，保存时检查编辑版本；页面过旧会要求重新读取，避免覆盖其它编辑。

```bash
~/Nuwax-embodied-harness/bin/neh config
~/Nuwax-embodied-harness/bin/neh status
~/Nuwax-embodied-harness/bin/neh start --wait
```

初次接入按照[配置说明](配置说明.md)和[架构与机器人接入](架构与机器人接入.md)绑定真实输入。在业务控制台确认状态更新、相机画面及雷达/惯性数据已到达。没有设备输入时显示等待或缺项是预期行为，安装本身不会生成模拟数据或完成标定。

## 3. 完成一次建图

确认所选链路的输入和程序可用后，在控制台进行：

1. 创建并选择一个有明确名称的地图工作区。
2. 启动建图，检查有效定位与地图是否持续更新。
3. 在实际设备允许的控制方式下采集环境，观察轨迹与地图轮廓。
4. 结束本次采集并保存地图，查看保存结果与资产状态。
5. 再次使用时激活已保存地图，并按返回状态完成定位或重定位。

二维地图适合看平面轮廓，三维视图适合看高度、支撑与完整空间结构。使用三维链路时，切换到二维视图不会改变导航算法。

保存地图与停止建图是不同操作，按各自回执确认。需要续建时还须具备对应后端检查点；已有地图图片不能代替完整资产。

## 4. 使用导航、探索和记忆

**导航：**在已定位的目标地图中选点，检查目标位置后发起任务。选点导航只要求到达位置；通过接口显式指定朝向时，才检查最终朝向。三维视图选点应落在实际地面，并已配置机体到支撑面的距离。观察任务的最终结果，而不仅是“已受理”。

**探索：**根据场地设置边界和预算，发起探索并查看是否已选出可行目标。需要中断并保留进度时，使用暂停并保存，等待停车和检查点结果；恢复会重新定位并检查条件。

**感知与记忆：**启用已配置模型的感知，查看检测结果和物品列表。记忆绑定当前地图；只有观察位置的记录会保留“仅观察”含义。语义地图另需启用并配置决策服务，当前为实验能力。

这些功能的依赖与限制见[功能介绍](功能列表.md)。

## 5. 连接应用或智能体

网关运行后，可以只读检查状态和接口目录：

```bash
curl -fsS http://127.0.0.1:8766/api/health
curl -fsS http://127.0.0.1:8766/api/agent/tools
```

MCP（模型上下文协议）入口是 `http://127.0.0.1:8766/mcp`。也可以使用只依赖 Python 标准库的客户端：

```bash
python3 ~/Nuwax-embodied-harness/current/source/clients/robot_client.py --url http://127.0.0.1:8766 info
python3 ~/Nuwax-embodied-harness/current/source/clients/robot_client.py --url http://127.0.0.1:8766 tools
```

健康接口成功表示网关可响应。建图、导航或识别是否可用，还需查看各自的输入与任务结果。调用方法见[智能体接入](智能体接入.md)。

## 没有机器人时验证基础流程

正式安装完成后，可以使用当前版本环境运行无机器人检查：

```bash
~/Nuwax-embodied-harness/current/venv/bin/python ~/Nuwax-embodied-harness/current/source/scripts/diagnostics/offline_platform_smoke.py
```

它使用模拟的静止状态和图像，启动真实本机网关，检查能力发现、抓图、制品读取、感知编排和地图创建等流程，然后关闭进程。不连接机器人，也不下载或加载识别模型。

这项检查适合确认软件接线，实机运动、模型识别与建图精度需分别验证。已有旧安装或自定义安装根时，将命令中的`~/Nuwax-embodied-harness`替换为实际路径。
