# 发布与兼容性

Nuwax Embodied Harness（NEH，具身运行框架）通过固定源码修订、目标平台构建和安装配方交付正式版本。本文更新于2026年10月14日；软件包的发布与机器人现场功能验收分别记录。

## 获取哪个版本

代码默认入口为`main`（主分支），日常设备安装使用[仓库发布页](https://github.com/Molun0301/nuwax-embodied-harness/releases)的版本目录和引导程序。仓库保持私有，需要相应读取权限。安装、更新与历史版本选择见[轻量安装与自动发布](轻量安装与自动发布.md)。

首发配置为`0.1.0`，工作流要求全部声明目标完成构建、依赖核验和离线流程检查后才公开完整版本。是否已经可下载以发布页和管理页取得的目录为准；失败的工作流或未公开草稿不算已发布版本。

## 当前软件交付范围

| 范围 | 当前范围与条件 |
| --- | --- |
| 正式业务包 | Ubuntu24.04的x86_64和aarch64、Go2 Ubuntu20.04的aarch64/Python3.8，共3个平台 |
| 模块组合 | 每个平台提供基础、几何、导航、FastLIO2、PointLIO及两种建图加导航组合，共21个目标；精确集合见安装说明 |
| 网页与命令行 | 同一管理引擎提供安装、配置、启停、更新、回退、迁入和管理自更新；业务未启动时管理页仍可用 |
| Go2官方依赖 | 固定官方SDK来源和预编译DDS库；首次安装生成Python接口适配缓存。此软件验证不代替设备通信或运动验收 |
| 依赖与模型 | 与轻量业务包分离，安装时按来源、版本、大小和摘要下载并复用缓存 |
| 视觉、跟随与语义记忆组合 | 尚未进入首发默认目录，所需固定推理依赖和完整模型配方待补齐；不将源码可选模块视为已发布组合 |
| 二维组合 | 已有实现和本地验证，尚未纳入当前21包的正式构建矩阵 |
| 其它机器人 | 可通过标准装配接入；每种设备的数据、标定、执行与功能须单独验收 |
| 三维导航与探索 | 包含已有实现和测试；现场输入、精度、运动与复杂地图计算长尾仍需按实际设备评估 |
| 语义地图 | 实验能力；真实环境用途识别和导航闭环不作普遍承诺 |
| 访问与密码 | 管理页默认免密码，可设置密码；业务网关通过管理服务代理，部署方按网络环境设置访问边界 |
| 许可证 | 项目级许可待定，当前不声明开源或商业再分发授权 |

源码模块安装、旧Go2开发更新和历史档案部署仍各有用途，详见[部署文档](部署文档.md)。它们的历史依赖批准状态不会因新增正式产品路径被自动改写。

## 名称兼容

以下内部名称继续使用，不能做全仓库字符串替换：

| 保留内容 | 示例与原因 |
| --- | --- |
| Python/Rust（编程语言）包和程序 | `nuwax-*`、`nuwax_robot_bridge`；避免改变导入和构建 |
| 环境变量 | `NUWAX_*`、设备专用键；已有配置继续可读 |
| 协议与工具身份 | 消息通道、响应字段和协议服务器名称；避免破坏客户端 |
| 系统服务与数据目录 | `nuwax-host-gateway`、`/var/lib/nuwax_robot_bridge/`；避免影响运行部署 |
| 已有源码目录 | `/home/unitree/nuwax-robot-bridge` 等实际路径；仓库改名不会移动设备文件 |

旧克隆可在仓库根更新自己的远端地址，HTTPS或SSH（安全远程连接）任选与现有认证方式一致的一种：

```bash
git remote set-url origin https://github.com/Molun0301/nuwax-embodied-harness.git
```

设备路径与系统服务不随该命令改名。合作方和自动化配置中的仓库链接也需核对。

## 设备投入使用前的验收

安装成功说明文件、依赖和软件入口完成准备；现场还需核对实际传感器输入、定位和地图、运动执行、停止与异常恢复。视觉与模型组合必须使用与设备软件栈匹配且完成加载验证的依赖。长期运行还需观察磁盘增长、断线恢复及场景计算开销。

详细能力见[功能列表](功能列表.md)，正式安装与回退见[轻量安装与自动发布](轻量安装与自动发布.md)。
