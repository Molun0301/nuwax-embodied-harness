# 功能介绍

Nuwax Embodied Harness（NEH，具身运行框架）把机器人对环境的观察、对空间的表达和实际任务执行放在同一个平台里，适合搭建机器人实验系统、室内空间感知应用，以及由上层智能体编排的移动任务。

本文对应当前源码。具体设备能用哪些功能，由传感器、已安装模块、配置和运行状态共同决定。逐项实现与验证情况见[项目功能与实现情况清单](项目功能与实现情况清单.md)。

## 地图与定位

### 两条完整链路

| 链路（`geometry.pipeline`） | 输入与算法 | 空间表达 |
| --- | --- | --- |
| 二维激光链 `slam_2d` | 规范二维扫描与里程计；二维建图、图定位、波前探索、二维导航 | 平面占据栅格与完整二维图 |
| 三维激光惯性链 `lio_3d`（默认） | 三维点云与 IMU（惯性测量单元）；FastLIO2（快速激光惯性里程计）、PointLIO（逐点激光惯性里程计）或设备自带里程计 | 三维点云、实测地面、水平切片二维栅格 |

链路一次决定建图、探索与导航的组合。网页的 2D/3D 切换只改变显示。三维前端可选回环校正：确认回环后用优化后的轨迹重建本次建图的地图（见[双LIO建图与回环纠偏](双LIO建图与回环纠偏.md)）。

### 地图是长期资产

- **建图**：开始建图（新图或续建已保存地图）→ 保存（建图继续进行）→ 结束会话。新建的地图名已存在时拒绝；保存时换新名字即另存。
- **加载与重定位**：加载地图后自动重定位，成功后才能导航。三维重定位用最近 2 秒的雷达帧先做局部配准，不行再做全局配准；对称房间可能匹配失败。只能查看的二维地图（缺少完整二维定位图）加载后不能重定位，也不能续建。
- **同名记忆库**：每张地图有同名记忆库，随地图自动打开和切换；删除地图时一并删除。
- **禁行区**：每张地图一份，可画直线、矩形、圆形和多边形，选择内部或外部禁行；保存后下一次规划就使用，不会先让机器人停下。
- **地图清理**：对已保存的三维地图预览并去掉残影（例如走过的行人），另存为新地图，源地图不变。

地图目录保存栅格、点云、后端检查点和原始扫描；只有一张栅格图片不足以恢复定位或续建。

### 在线去动态

三维建图时，按雷达射线判定“曾被看见为空”的位置，删除走过的人等动态物体留下的历史点；实时障碍仍保留给导航。一直静止、前后都没有被射线穿过的人体不保证删除。

## 导航与探索

### 前往目标

可以前往坐标、按地名（需要地图带地理参考）、命名地点或记忆中的物体。任务提供进度、到达、失败与取消结果。默认到达位置误差 0.15 米以内即算到达，不检查最终朝向；指定朝向时才检查。

- **三维导航**：PCT（点云层析全局规划算法）全局规划（基于实测地面，考虑坡度、台阶与净空）+ SCAN（局部规划算法）局部规划与路径跟随。需要真实机体外形与执行端速度能力。
- **二维导航**：平面栅格规划与局部跟随，按机器人真实外形检查碰撞。
- **等待输入不拒绝**：定位、栅格或位姿暂时未就绪时，任务停在“等待输入”并写明缺哪一项，就绪后自动继续。
- **人的命令优先**：新的导航或运动命令直接替换旧命令，急停立即生效；所有运动经运动守卫，执行方停止续租后 0.75 秒内速度归零。

### 探索未知区域

探索在建图会话里进行：按边界线段和停止条件（时长、目标数、覆盖率）寻找未知区域，派出子目标并走普通导航链。二维用波前前沿，三维用共享表面前沿。单层探索还提供：

- 行程预算与返航：按总路程与保留余量决定何时返回起点（预算是路径估计，不是电量保证）。
- 暂停并保存：停止探索、保存地图和进度检查点；恢复时重新加载、重定位并继续。
- 连续 30 秒等不到所需输入时，以资源受限结束；结束时默认保存地图。

### 楼宇与跨层

登记建筑、楼层地图与设施（电梯、门等）后，可以前往目标楼层或逐层探索整栋建筑。中断后不自动续跑，由人重新下达。这依赖真实设施接口与已建好的楼层地图，目前没有通用的自主上下楼实机保证。

## 视觉感知与人物跟随

图像用于实时观察、拍照与识别。感知支持目标检测（默认 YOLO-World 开放词汇检测）、跟踪、可选分割，以及结合相机标定、深度或点云的空间位置估计；被判为机器人自身的检测（例如机械臂、脚）会被过滤。持续识别按“使用原因”运行：手动、探索、跟随、找目标任一在用就运行，全部释放就停止；只有关键帧写入记忆。

人物跟随复用视觉、导航与运动链；目标选择仍有局限，不承诺复杂遮挡下持续认出同一个人。

## 空间记忆与找目标

记忆把“看见了什么”“在哪里看见”“有什么图像依据”关联到当前地图：

| 记录 | 用途 |
| --- | --- |
| 命名地点 | 门口、工作台等已知位置，可直接导航 |
| 场景记忆与观察事件 | 检索某次场景，追溯时间与照片 |
| 物品实例 | 多次观察合并为一个物品，维护位置与置信度 |
| 场景区域 | 语义地图划分的区域与名称 |

检索支持文本与图像向量（默认本地模型），模型不可用时退回词法匹配。只有观察者位置、缺少物体几何依据的记录标为“仅观察”，不当作物体坐标。

**找目标**（`find_target`）在一个任务里完成：看当前画面 → 查记忆中的候选 → 前往候选旁边的观察位置（不会把物体本身的位置当目标）→ 到达后连拍复核 → 写回观察；复核失败就降低该候选的分数，换下一个。候选只要在当前地图上有位置就会前往，物体可能被移动等情况只写进诊断，到达后再复核。`explore_and_find_target` 在没有候选时先探索。检索匹配、导航到达和视觉确认是三个不同结果。

## 语义地图与空间关系图（实验能力）

平台从占据栅格中划分区域，选择带位姿的观察照片作证据，请配置的模型判断区域用途；证据充分时才采用名称，人工修改的名称受保护。已接入 Jev（决策服务）的远端文本接口和 OpenJev（本地图文决策模型）的独立服务接口。默认关闭，也不自动启动后台。

控制台可查看区域边界、名称候选、证据与修订，浏览区域、连接口、物品构成的关系图；智能体可查询节点与邻接关系、导出带编号的地图图像、获取区域之间的候选连接路线。连接路线只表达几何关系，没有经过导航检查。

## 控制台与开放接口

[控制台](http://127.0.0.1:8766/console)把地图、视频、任务、记忆、日志与设置放在同一界面，支持明暗主题与三维交互。设置支持多个配置方案，标明每项的默认值与生效方式；日志支持筛选、任务关联与导出。

MCP（模型上下文协议）、HTTP（超文本传输协议）接口与网页使用同一组能力和同一个任务执行器；每个能力就是一个 MCP 工具。地图、视频与状态通过数据流更新，网页断线不会取消已受理的任务。接入方法见[智能体接入](智能体接入.md)。

## 使用与验证边界

| 范围 | 当前说明 |
| --- | --- |
| 仿真平台（`unitree_sim`，Go2 型号） | 当前版本在办公室场景完成实时建图中的选点导航（到达误差约 3—13 厘米）、找目标导航与到达复核、运动中急停；有边界探索在该场景按时长结束但未完成子目标 |
| Go2（宇树四足机器人） | 有设备接入与现场使用记录；当前版本的实机建图、导航与探索需要重新验收（旧地图格式不迁移，需重新建图） |
| 通用设备与二维雷达 | 标准数据入口、二维完整链与思岚雷达驱动已实现；二维现场运动待验收 |
| 三维导航与探索 | 规划与执行链完整；复杂真实地图仍有可行路线与输入质量限制 |
| 语义地图 | 几何、观察、标签与存储链已接通；真实用途识别与区域导航闭环未验收 |
| 识别与检索 | 需要真实模型、合适的类别和观察；替代检测器只能验证流程 |
| 性能与精度 | 没有适用于所有设备的固定帧率、延迟或厘米级精度承诺 |

机械臂操作、多机器人协作等不在当前能力承诺内；外部设备操作只提供把指令转交外部设备并跟踪结果的接口。
