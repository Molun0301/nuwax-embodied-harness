7. **依赖环境复用**：使用明确的依赖文本、解释器、设备条件及源码拥有方配方版本比较，目录使用普通分配编号；不再因桥接器/安装器任意源码变化重建环境。兼容旧源码的前置检查函数签名。旧 schema 环境仍保留供原运行版本使用，首次新格式准备可能生成新环境。
8. **存储保留**：仅在成功的版本变更后清理已完成且不再引用的代际。保留当前、回退、非终态任务、恢复失败现场、活跃进程和共享依赖；保留数据、模型、源码与编译/下载缓存。未登记的旧管理器不自动删除。清理失败只报告警告，不回退已成功安装。
9. **IPv6**：服务监听地址族与端口预检、回环访问地址一致。
10. **protoc 缓存**：固定官方 HTTPS 来源和版本，分阶段准备并发布；完成后复用小型元数据，不反复读取 ZIP、计算应用哈希或解包。旧无记录缓存首次重新准备，之后可离线重用。既有 rustup 完整性机制未改。
