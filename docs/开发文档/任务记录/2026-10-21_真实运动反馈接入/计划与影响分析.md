# 真实运动反馈接入：计划与影响分析

## 授权与范围

用户确认统一修复：直接读取真实运动数据，局部控制复用原 SCAN。仅已有云端候选；不连接开发机/实机，不提交推送，不更改物理尺寸、裁判、容差或预算。无仓库 AGENTS.md，遵循贡献指南的契约同步和具名验证要求。

## 现状与变更

1. Go2 守卫已经从 SportModeState 原始 world 线速度经同样本姿态逆旋转取得 body 速度，gyro 是 body 角速度；现有反馈只供停车判断。复用它，不把 FAST-LIO 占位零或 applied 命令解释为测量。
2. 在原守卫回复中增加独立 optional measured_motion_feedback，保持来源、原采集时间、原接收单调时间及来源有效期限。读取缓存不续期；缺失/不支持/无效仍为缺失，不影响原租约/取消/停车，不新增导航准入门禁。
3. Rust 客户端仅接收有效样本；runtime 经 NavMotionPort 独立读取，PlannerWorker 独立 measured 版本，位置未动但速度变化也使旧结果退休。APPLIED 字段继续只表示命令应用。
4. SurfaceFollower 用真实 body twist 构造 SCAN 可选运动边界；线速度使用地图位姿姿态表达在 map 轴，保留测速与位姿的不同采集时点，不假称同步。body gyro 不直接冒充 Euler yaw rate，依测量姿态转换；无所需姿态则 yaw rate 未知。无真实加速度则 None。
5. SCAN native 同伴负责 Option v/a/yaw_rate 与历史轨迹接续；实测优先，未知沿用明确的历史计划导数，首次无历史只保留初始边界假设。恢复原 vx/vy/ω 输出，不再把全向硬改差动，实际平台能力仍由原配置声明。

## 来源与适用边界

Go2 实测反馈和定位 pose 是独立流，不把最新缓存当永久当前，也不通过 pose 差分猜运动。当前无同步器，不声称两者在同一时点；体轴速度在当前地图姿态下重新表达是明确的表示近似，不增加虚构测量。完整三维 twist 沿用现有适配器声明的受控参考点；Go2 的物理参考原点未获独立官方确证，不声称已标定为机体中心，不添加未知杆臂。Point-LIO 原有 IMU→body 杆臂以及混合轴系不在此旁路改写；FAST-LIO/pose-only 消息未证明的零继续未知。

## 验证计划

- Python：命令非零测量为零、body/world 旋转、占位零缺失、时间重复/乱序/过期、编码保留来源与期限、缺失不门禁。
- Rust：可选字段兼容、测量版本独立于命令、旋转仅一次、倾斜姿态 yaw 导数、原期限不续期、测量缺失不替代为命令、worker 迟到结果退休。
- 原取消、来源过期、停车与命令交付回归；不以单测代替实机或原录完整闭环。

navigation.motion_feedback 日志分别输出真实来源source_id/时间和SCAN边界分量来源 Measured、PreviousTrajectory、InitialZeroAssumption、PreviousControlEstimate。后两类不是实测。getter也提供给模拟器诊断。

## 入口缺省倒退策略：实施前合同与影响分析

本轮确认 SCAN 前向是偏好而不是默认禁止倒退。只改目标请求的来源合同，不把未知硬件变为具备倒退能力，不全局翻转旧二维 GoalOptions::default。

当前公共 protobuf bool 没有字段存在性，无法从旧 false 判断调用者是否省略。新增兼容 bool use_profile_reverse_default（field 15，旧消息默认为 false）：旧消息按原 allow_reverse 执行；新入口省略时发送 allow_reverse=false + use_profile_reverse_default=true；新入口显式 true/false 发送原值 + 标记 false。标记 true 同时 allow_reverse=true 属矛盾编码，Geometry 返回参数错误，不默默覆盖。标记 true + false 是规定的缺省编码，不表示用户禁倒退。

Python NavigationGoal 用 Optional[bool] 保留缺省 None，网关不提前填硬件默认；provider 和 Rust 视觉入口保留此三态并生成同一 wire 编码。Geometry 使用自己已配置的 profile 一次解析：仅 Mls3D 缺省 true，其余保持 false。解析后的 LCM 和 GoalOptions 仍是 bool，后续不可再猜缺省或覆盖显式值。硬件通道上限及租约/停车链完全不变。

验证覆盖新缺省、显式 false/true、旧 wire false/true、旧二维缺省、矛盾字段、Python/protobuf 与视觉/protobuf 往返，以及默认允许不增加未知硬件的 reverse/lateral 上限。先前 spacing-final 入口修复前 runtime 已独立166通过、0失败、1性能忽略、5UDS环境排除（172总数），49.15秒；入口修改后重新编译和验证，不混用版本。
