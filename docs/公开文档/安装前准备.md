# 安装前准备

Nuwax Embodied Harness（NEH，具身运行框架）用[安装与更新](安装与更新.md)中的一行命令安装，然后在管理页选择机器人与模块。本页说明设备要满足的条件、源码开发环境，以及接入前需要收集的设备信息。

## 正式安装环境

| 项目 | 要求 |
| --- | --- |
| 系统 | Debian、Ubuntu 及衍生系统；云端预编译覆盖 Ubuntu 24.04 x86_64 与 Ubuntu 20.04 aarch64（Go2） |
| 架构 | `x86_64` 或 `aarch64`（64 位 ARM 架构）；32 位系统不在安装范围 |
| 账号 | 普通用户执行；安装系统依赖、系统服务时终端会单独请求管理员密码 |
| 网络 | 系统软件源、GitHub（代码托管平台）、Python 包源和所选模型的下载源可达；终端需有 curl（下载工具） |
| Python（编程语言） | 由安装入口按需准备；业务代码支持 3.8—3.12 |
| 磁盘 | 基础网关先预留数 GiB（吉字节）；原生编译、视觉与记忆模型需要更多空间 |
| GPU（图形处理器） | 基础网关不需要；本地视觉与记忆模型按所选模型配置 |

五个程序在匹配平台上可以下载云端预编译产物；FastLIO2（快速激光惯性里程计）与 PointLIO（逐点激光惯性里程计）始终在设备本机从源码编译，选用它们时设备要能完成原生编译。

Go2（宇树四足机器人）所需的宇树软件开发包和通信依赖由安装器按固定官方配方下载并缓存。Jetson（嵌入式计算平台）上的本地视觉和语义记忆需要与 JetPack（厂商软件栈）匹配、可导入的 torch/torchvision（张量与视觉库），装在系统目录或当前用户目录均可；安装器复用已有版本，在生成安装计划时检查。

这些是安装范围，不表示每种系统与模块组合都在实机上验证过。Windows 与 macOS 可以用浏览器访问已部署的设备，没有原生一键安装。容器或虚拟机需要自己处理传感器、网络和硬件访问。

## 源码开发环境

需要修改代码时，从主分支取得源码（仓库公开，可匿名克隆）：

```bash
git clone --branch main https://github.com/Molun0301/nuwax-embodied-harness.git
cd nuwax-embodied-harness
```

缺少基础工具时，由管理员安装：

```bash
sudo apt-get update
sudo apt-get install -y git python3 python3-venv
```

源码目录里的 `./install.sh` 是本机模块安装器，用法见[开发工具使用指南](开发工具使用指南.md#源码开发安装)。安装前可以先检查环境和查看计划，两条命令都不安装软件：

```bash
./install.sh doctor --preset basic --robot customrobot
./install.sh install --preset map3d --robot customrobot --dry-run
```

`doctor`（环境检查）逐项列出通过、提示和需处理，有需处理项时退出码为 1；它不下载软件，也不验证传感器。`--dry-run`（只查看计划）列出模块、依赖和构建步骤。`--preset` 可选 `basic`（基础网关）、`map2d`（二维激光建图）、`map3d`（三维激光惯性建图）。

## 需要预先知道的设备信息

不接运动也可以先体验基础软件。准备接入功能时，逐项收集：

- 机器人和传感器型号、固件版本、连接方式、厂商开发包来源。
- 数据单位、真实采集时间、时钟关系、每帧坐标系和传感器外参（传感器到机体的空间关系）。
- 选用二维激光、三维激光惯性还是设备自带里程计。
- 机体尺寸、允许的速度与运动方式、独立停止方法、执行反馈。
- 地图、日志、模型和记忆数据的存放位置。

接入步骤和数据契约见[架构与机器人接入](架构与机器人接入.md)。
