# 升级与恢复

本页适用于 Nuwax Embodied Harness（NEH，具身运行框架）的模块安装。已由系统服务管理的 Go2（宇树四足机器人）使用[设备更新入口](部署文档.md)，两种安装状态不能混用。

## 更新前记录什么

在源码根目录记录当前版本和模块：

```bash
git branch --show-current
git rev-parse HEAD
./install.sh list
```

记录当前机器人方案、安装目录和实际数据位置。完成或取消正在运行的任务，确认机器人停稳，再停止网关：

```bash
./install.sh stop
```

按数据的重要性保存一份可恢复的数据副本，至少包括当前机器人方案、地图完整资产、记忆数据库及关联文件。数据库应在相关进程停止后保存；地图不能只保留缩略图。默认位置和自定义路径规则见[安全与数据说明](安全与数据说明.md)。

## 更新模块安装

先确认没有需要保留的源码修改：

```bash
git status --short
```

有修改时先处理其归属，不用强制覆盖或清理命令掩盖冲突。当前分支配置了上游、工作区干净时：

```bash
git pull --ff-only
./install.sh install --dry-run
./install.sh install --yes
./install.sh doctor
./install.sh start
```

`--ff-only`（仅快进更新）遇到分叉会停止，避免自动生成意外合并。更新后读取接口、检查数据与功能，再进行该设备的任务验证。使用自定义目录时，每个安装管理命令都带上原来的 `--install-dir`。

安装器默认沿用上次模块选择；使用 `--modules` 或 `--preset` 会指定完整目标集合。增量加入一个能力请用 `add`，不要误把完整选择当作追加。

```bash
./install.sh add navigation --yes
./install.sh remove perception --yes
```

这些操作前同样需要停止网关。删除视觉会同时移除依赖它的人物跟随，计划中会明确列出。

## 安装失败后如何恢复

安装器先在独立目录创建新环境，只有依赖、构建和产物检查通过后才切换 `current`（当前安装链接）。下载、编译或准备模型失败时，上一个有效安装环境保留；日志在安装根的 `logs/` 中。修复原因后重跑相同安装命令。

**安装环境保留不等于源码和业务数据自动回退。**模块安装的启动器仍使用这个源码目录。如果已更新源码，旧环境可能不兼容新代码。需要回到更新前状态时，先恢复自己记录的源码版本，再核对配置和数据格式；只有已确认兼容时才能复用原数据。存在未提交修改时由维护者处理源码回退，避免覆盖工作。

安装产物损坏时，停止网关后执行：

```bash
./install.sh install --repair --yes
./install.sh doctor
```

修复针对当前源码和模块选择，不是降级命令。`./install.sh rollback` 属于另一套档案部署入口，不能用于本机模块安装。成功升级通常清理上一安装环境，因此也不能假设有任意历史版本可一键切回。

## 迁移与移除

安装产物内有绝对路径。需要换源码目录、换磁盘或换主机时，在新位置重新安装，显式迁移配置与数据并重新验证，不能只移动 `current` 链接。

暂停使用时执行 `stop` 即可。模块管理支持移除可选模块，基础模块不能通过 `remove core` 删除。当前没有一键清空所有数据的卸载命令。完整退役前先核对数据去向、安装方式和自定义路径，再由管理员移除明确的安装产物；系统共享依赖和现场数据不能随源码目录一并清理。
