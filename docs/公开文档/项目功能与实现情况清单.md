# 项目功能与实现情况清单

核对日期：2026年9月29日。代码基线：`169d34830f9d7586e2c5ad6d9c51533db451e366`。

本文按模块列出 Nuwax Embodied Harness（NEH，具身运行框架） 当前功能，并区分代码实现、使用条件和验证情况。核对依据为当前源码、能力注册、默认配置和项目已有验证记录；本次整理没有重新启动设备、执行运动或重跑算法验收。历史验证只代表对应日期、版本与场景。

本轮已完成导航等待状态与几何查询缓存修正，并通过本机回放和专项回归；尚未取得对应实机复验结论，本文不将其表述为实机已验收。

## 一、状态口径与当前结论

| 实现状态 | 本文含义 | 不代表什么 |
| --- | --- | --- |
| 已实现 | 有实际处理逻辑，相关职责已接入项目调用链 | 不代表默认开启、所有设备可用或没有缺陷 |
| 已接通，待完善 | 主要流程存在，但关键效果、稳定性或配套能力仍有明确缺口 | 不作为完整功能验收通过 |
| 实验性实现 | 已有代码或本地闭环，用于验证方案，适用范围有限 | 不作为成熟生产能力承诺 |
| 待实现 | 只有注册、配置、协议或占位入口，缺少实际执行后端 | 不能因界面或名称存在就判断可用 |
| 未提供／范围外 | 本次核对的产品链未提供，或由外部系统承担 | 不等于项目承诺会开发 |

当前最需要保留的事实：

- **地图、定位、任务、网关、记忆和控制台已有较完整实现。** 2026年9月29日已有同版 Go2（宇树四足机器人）部署、地图激活和重定位成功记录。
- **三维导航已有完整软件链，但当前实机稳定性未通过。** 同日同版命名地点导航出现“已经规划路径但不移动”，任务最终超时；现有记录仅完成取证，不能将失败视为已修复。
- **探索、跨层移动与跟随不能一概标为可交付。** 本地模拟、历史短距离实走、完整自主任务和当前版本实机验收是不同层次。
- **语义区域与关系图已实现，现场自动识别房间用途仍是实验能力。** 已保存的房间名称不等于模型本轮自动识别正确。
- **G1（宇树人形机器人）已有可对接的设备接口，当前平台适配待实现。** 本项目已预留通用接入与G1入口，可沿现有接口补齐驱动和能力；这是开发项，不是通用平台或家务方案的障碍。树莓派整机适配及独立分割模型后端也待实现。
