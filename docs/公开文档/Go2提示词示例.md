# Go2 任务提示词示例

这些示例用于已经连接 Nuwax Embodied Harness（NEH，具身运行框架） 的上层智能体。Go2（宇树四足机器人）的数据、标定、地图和执行链应按任务需要配置完成。连接方法见[智能体接入](智能体接入.md)。

工具名称与参数以当前网关发现结果为准。示例表达任务目标，不预先假定某个模型、地图或运动功能已经就绪。

完整系统提示词见[机器人智能体提示词](机器人智能体提示词.md)。可先配置该提示词，再将下列场景作为日常用户任务。

## 通用执行约定

可将以下内容放入智能体的系统提示词或机器人任务说明中：

```text
你通过 Nuwax Embodied Harness（NEH，具身运行框架） 操作真实机器人。开始任务前，读取当前工具目录，并按实际参数结构调用。

先确认机器人、目标地图、定位以及任务所需能力的状态。使用工具给出的地点、物品和坐标，不猜测目标位置。

长任务返回后保存任务标识，按回执建议查询或等待。已受理不等于已经行动，运行中不等于已经完成。报告失败时保留具体阶段和原因。

响应丢失时先查询原调用或任务。不要因超时就重新发出相同运动操作。用户要求停止时，使用可用停止或取消入口，并核对实际停止结果。

地图、记忆、语义区域和导航结果各有适用范围：仅观察记录不是物体坐标；区域相邻不代表机器人可通过；导航到达后，现场确认需要新的观察。

报告任务结果时说明完成了什么，并引用实际任务结果、图像或观察。证据不足的内容明确保留未知。
```

## 前往命名地点并观察

```text
请检查当前地图中是否有可导航的“会议室门口”。若目标和导航条件齐备，前往该位置；到达后获取一张新图像，并简要描述门口情况。

如果有多个同名候选，先列出差异让我选择。如果没有对应地点或路线不可执行，说明原因，不自行猜坐标或开始探索。
```

适合验证命名地点查询、导航任务和到点观察的完整流程。

## 在限定区域内探索

```text
请在当前地图和设备允许的范围内，从当前位置开始探索，半径最多 2 米，总时限 3 分钟。使用当前工具支持的边界与停止条件表达这些限制。

先检查输入和运动条件，受理后跟踪任务进度。任务结束时分别报告探索结果、停止状态和地图是否保存成功。如果一直没有可行目标，说明具体阻塞原因。
```

当需要暂停时，可以追加：

```text
请暂停当前探索，停车后保存地图和进度。确认检查点保存结果，并告诉我之后能否恢复。
```

## 寻找曾经看见的物品

```text
请在当前地图的记忆中查找“红色椅子”，列出最相关的候选、最近观察时间和空间依据。

如果有唯一且允许导航的候选，请前往它的建议观察位置，再获取新图像确认。若只有观察记录或候选无法区分，先说明还缺什么证据。
```

该任务依赖真实视觉与记忆模型。检索结果可能反映历史观察，最后的现场复核需要新的输入。

## 了解空间结构

```text
请读取当前语义地图与空间关系图，概述已知区域、连接关系和待确认的名称。获取带编号的地图图像后，将文字说明与图像编号对应起来。

只做查询和说明。候选标签保持候选状态，区域连接不解释为已经验证的可通行路线。
```

适用于已启用实验语义地图的环境。区域用途判断仍取决于实际观察证据。
