# 安全与数据说明

本页说明 Nuwax Embodied Harness（NEH，具身运行框架）的访问边界、数据存放位置与外部服务使用，供接入和部署时参考。

## 访问控制

| 入口 | 监听 | 访问控制 |
| --- | --- | --- |
| 设备管理页（默认端口 8765） | 所有网卡 | 默认免密码；可在管理页或用 `neh password --stdin` 设置密码（至少 8 个字符，只保存加盐摘要）。启用后，管理页和经它转发的控制台、接口都要求登录会话 |
| 业务网关（默认端口 8766） | 只监听设备本机 | 没有用户登录或令牌认证；能访问网关就能发起机器人任务 |

经管理页转发的写请求要求同源浏览器（管理操作还核对会话的防跨站请求标识），或 JSON（结构化数据格式）请求体的机器客户端。

**未设置密码时，同一网络中的任何人都能经管理页操作机器人。** 在共享网络中使用时设置密码，或只在受控网络中使用；不要把管理页或网关端口直接暴露到公网。智能体等程序客户端在启用密码后用 SSH（安全远程连接）隧道访问本机网关：

```bash
ssh -N -L 8766:127.0.0.1:8766 robot-host
```

`robot-host` 是已配置的连接别名。保持该终端连接，在开发电脑上使用 `http://127.0.0.1:8766`。

需要在网关外加认证或代理时，代理要支持长连接、数据流和文件下载，并把配置 `gateway.public_base_url` 设为调用者可达的地址（图像等文件的下载地址由它生成）。容器中的 `127.0.0.1` 指容器自己，要填容器能访问到的设备地址。NEH 不提供组织级身份管理。

## 数据存在哪里

`安装根` 默认 `~/Nuwax-embodied-harness`：

| 内容 | 位置 | 管理建议 |
| --- | --- | --- |
| 配置方案 | `安装根/config/profiles/` | 可能含设备地址与密钥，按私有配置保存 |
| 地图 | `安装根/data/maps/地图名/`（含 `geometry/` 地图文件、`meta.json`、禁行区与 `memory/` 记忆库） | 整个地图目录一起备份 |
| 无建图机型的记忆库 | `安装根/data/memory/default/` | 与照片一起保留 |
| 模型 | `安装根/data/models/` 或配置中的自定义路径 | 记录来源、版本与使用许可 |
| 日志 | `安装根/data/logs/`、`安装根/logs/` | 按容量轮转；导出前脱敏 |
| 临时图像制品 | 配置 `gateway.artifact_dir`（默认在 `安装根/data/` 下） | 按保留天数、数量与总大小自动清理 |
| 建图输入记录 | 地图根同级的 `mapping_recordings/` | 原始传感器与位姿，用于离线排障，可能很大 |
| 程序与依赖 | `安装根/releases/`、`安装根/python-environments/`、`安装根/cache/` | 由管理程序管理 |

位置可能被配置修改，升级或迁移前以实际配置为准（见[配置说明](配置说明.md)）。卸载默认保留配置与数据；`neh uninstall --purge` 才删除。

## 何时访问外部服务

安装时下载系统包、Python 包、所选上游源码与模型；基础网关不下载视觉或语义模型。

运行时是否把图像、文本或场景信息发到外部服务，取决于配置：例如感知的 OpenAI 兼容视觉接口（`perception.openai_*`）、远端文本向量服务（`memory.embedding_*`）、语义地图决策服务（`semantic_map.*`）、按地名导航的 OpenStreetMap 地名检索（`map_cloud.nominatim_url`）。使用远端服务前确认数据许可、服务地址与密钥保管；本地后端也要核对模型的实际缓存与联网行为，不能因为部署在本机就认为所有处理都离线。

## 真实机器人运行

接入方负责真实标定、机体参数、执行端、独立的硬件停止方法和场地验证。运动守卫负责统一仲裁、急停与超时归零（执行方停止续租后 0.75 秒内归零），它不是硬件急停，也不构成功能安全认证。

先验证不运动的数据接入，再验证速度、停止与故障行为，最后执行导航等组合任务。上层智能体应查询实际状态、遵循能力参数和任务结果，不能用语言推断代替定位、通行或停止结果。

## 报告安全问题

通过[项目问题区](https://github.com/Molun0301/nuwax-embodied-harness/issues)联系维护者时，先提供影响概述与脱敏复现信息，并约定敏感细节的接收方式；约定之前不公开密钥或可利用的细节。本项目尚未发布漏洞响应时限或长期支持承诺。
