## 最终算法边界

保留原 g、平移启发式倍率 4，以及原最终朝向排序项。令 R 为原剩余距离度量、v/ω 为前向/角速度上限、e 为归一化朝向误差：

- 直接尝试：`h = 4R/v + 4 max(|e|-π/2, 0)/ω`；目标进入前半平面后恢复原距离排序。
- 沿参考绕行尝试：`h = 4R/v + 4|e|/ω`；朝向参考线上前方一个机体半径（至少一个层析单元）的引导点。R 保留原沿参考剩余距离与偏离距离；接近中间交接端时，在原允许横向端点 `0, ±c/2, ±c` 中取最小转向需求。

角度项沿用已有倍率 4，并非新增调参系数。理想纯转向减少角差 dθ 时，`dg=dθ/ω`、`dh=-4dθ/ω`，故 `df=-3dθ/ω`；并非 f 平局。这是加权排序，不声称可采纳性、最优性或真实执行时长。runtime 已将 Omni 转为仅前向 Differential；本补丁不引入倒退/侧移。

256 展开预算、14 个动作、精确七浮点位姿键、偏好权重、投影与完整扫掠、转弯半径、到达/最终朝向判据均不变。预算耗尽与离散候选耗尽使用准确错误文字，不再暗示已证明物理不连通。诊断输出仅在 test+profile 且显式环境变量启用时生效。
