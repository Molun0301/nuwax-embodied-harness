# 控制台使用指南

Nuwax Embodied Harness（NEH，具身运行框架）的业务控制台在浏览器中打开，无需安装扩展：在设备本机是 [http://127.0.0.1:8766/console](http://127.0.0.1:8766/console)，从其它电脑经管理页地址访问 `http://设备地址:管理端口/console`。

下面是基础模块安装后、尚未接入机器人时的界面，地图和视频为空。

![NEH基础控制台：尚未接入设备](图片/NEH基础控制台.png)

控制台有四个视图：**监控**（地图、摄像头、任务与服务状态）、**能力**、**日志**和**设置**。网页只发出与智能体相同的能力调用；关闭网页或断网不会取消已经受理的任务。

顶栏右侧的红色 **急停** 在任何视图都能点：立即停止所有运动、取消运动任务并停止导航与探索，不弹确认，按钮下方显示结果。机器人支持音量时，顶栏还有音量滑块，松手即设置。

## 先判断系统处于哪一步

| 界面现象 | 表示什么 | 下一步 |
| --- | --- | --- |
| 页面打不开 | 地址、端口或网络不通 | 检查管理页是否可用、业务是否已启动 |
| 已连接，机器人无数据 | 网关正常，设备输入未到达 | 接入设备状态、视频和传感器 |
| 有视频，没有地图 | 相机与空间链路条件不同 | 检查是否在建图或已加载地图、雷达/惯性输入与标定 |
| 地图可见，导航等待或失败 | 能显示不等于可执行 | 看任务消息中的等待原因（例如定位、栅格、位姿哪一项未就绪） |
| 任务已受理 | 已创建任务，尚未完成 | 继续看任务最终状态 |

右侧“任务状态”页签列出运行中和最近结束的任务，每个未结束的任务都有“取消”按钮；“服务状态”页签每个运行组件一张卡片，显示中文名、状态（运行中、未运行（按需启动）、已退出、未启用等）、进程号、运行时长，开启性能监控时还显示处理器和内存占用，已退出的组件写出退出原因；“最近日志”打开页面即显示最新记录。

## 地图

地图区上方可切换 **2D**、**3D** 和**语义地图**：

- **2D**：占据栅格、机器人、轨迹、路径和禁行区。三维链路的二维图是雷达高度附近的水平切片。
- **3D**：点云、高度与支撑面；“图层”中可选高度、完整点云、单层、地面、结构等显示样式。
- **语义地图**：区域、名称候选与关系图，需要先启用语义地图（实验能力）。

镜头可选“跟随”或“自由”，“定位机器人”回到机器人位置，滚轮或加减按钮缩放。切换视图不会改变底层算法。

建图会话在地图工具“地图”中管理：一行显示当前地图及其状态（建图中、已定位等），以及“重定位”“保存”“另存为”“结束会话”“新建地图”和“地图列表”。点“新建地图”或“另存为”，同一行出现名称输入框，填写后回车或点确认，按 Esc 取消。“地图列表”默认收起，点开后列出已保存地图的名称、更新时间和大小，当前地图高亮；每张地图可“激活”（加载并重定位）、“续建”或“删除”，列表过长时在下拉层内滚动。激活、新建、续建、结束会话和删除前会确认；失败时直接显示原因。这些按钮调用的就是智能体使用的同名能力，见[智能体接入](智能体接入.md)。控制台在建图、加载地图、导航或探索期间显示地图与定位；会话结束后隐藏缓存的旧地图。地图加载后会自动重定位，定位成功才能导航。

## 导航与探索

发起前确认机器人处于允许测试的场地，设备的独立停止方法可用。

打开地图工具中的“导航”，有四种方式：

- **选点导航**：双击地图选目标（三维视图请双击地面）；双击的第二下按住并拖动，按下处是目标位置，拖动方向是到达朝向，拖动时地图不动。单击并拖动仍是旋转平移地图。可填写目标机体高度，点“开始导航”。默认到达位置误差 0.15 米以内即算到达；只双击不拖动时不检查最终朝向，拖动设定了朝向时还检查朝向。点“取消导航”取消当前任务。
- **按名称**：输入或从候选中选择当前地图记忆里的地点、区域或物品名称，点“前往”；勾选“到达后核对”时到达后会连拍核对目标。候选来自已标记的地点和区域，点“刷新名称”重新读取。
- **自动探索**：填写地图名称（留空用当前地图）、最长运行时间，可选总路程、返航余量和“结束后返回起点”，点“开始探索”。探索在建图会话中进行，结束时默认保存地图。“暂停并保存”会停止探索并保存地图与进度；之后在“已保存的探索”中选择并点“继续所选探索”，恢复时会重新加载地图并定位。“停止探索”只停止探索，建图会话保留。两个按钮在探索任务受理后即可使用；探索还在准备、尚未开始时暂停只结束任务，没有可保存的进度。
- **跨楼层**：选择已登记的建筑与目标楼层，填写目标层地图中的坐标后“前往目标层”；“逐层探索建筑”依次探索各层；“导入楼层配置”登记楼层与设施。跨层依赖实际设施与已建好的楼层地图。

任何新的导航或探索命令都会替换正在进行的运动任务，旧任务以“已取消”结束。导航任务停在“等待输入”时，消息会写明缺的是哪一项，输入就绪后自动继续，无需重新提交。

## 移动与转向

地图工具中的“运动”提供各种机器人通用的移动与转向。打开后，按住键盘按键机器人持续移动，松开即停：

| 按键 | 动作 |
| --- | --- |
| W / ↑ | 前进 |
| S / ↓ | 后退 |
| A / D | 向左 / 向右平移 |
| Q / ← | 左转 |
| E / → | 右转 |

按键可以组合，例如 W+Q 边走边转。面板上的 Q W E / A S D 六个按钮也可以用鼠标按住。速度取面板上的线速度（米/秒）与角速度（弧度/秒），并由运动守卫按设备上限限制。光标在输入框里时按键不控制机器人；页面失去焦点或关闭面板时立即停止。机身动作、姿态、速度档位、避障等设备专有功能在“能力”视图调用。需要立即停下时点顶栏“急停”。

## 禁行区

打开“禁行区”，选择形状（直线、矩形、圆形、自定义多边形）、禁行方向（内部禁行或外部禁行）和边界宽度，点“开始绘制”：直线、矩形和圆形用鼠标拖拽，多边形逐点单击后“完成多边形”。“保存禁行区”后，下一次规划即使用新的禁行区，不会先让机器人停下。禁行区属于当前地图。

## 清除残影

“清除残影”对已保存的三维地图离线去除行人等移动物体留下的点：选择已保存的地图，调整清除力度（0 保守、100 激进），点“预览残影”。面板显示原图与红色删除候选；确认后输入新地图名称，点“确认并另存为新地图”。源地图不变，另存后需要时再加载新地图。没有可用原始扫描的旧地图只做离群点清理，预览会说明这一点；一直静止的人体不保证被清除。

## 摄像头、识别与记忆

“摄像头与识别”显示相机画面和检测框。标题栏的“开启检测”加入一个持续识别的手动使用原因，开启后按钮变为“关闭检测”；关闭只移除手动原因，探索、跟随或找目标仍在使用时识别会继续。视觉识别在设置中未开启时，“开启检测”不可用，旁边的齿轮按钮跳到设置页“视频与视觉识别”，开启后重启业务生效。画面持续刷新即显示“视频可用”，与设备时钟是否准确无关。地图与视频互换用地图栏的“视频”按钮。只有关键帧写入记忆。

“物品”面板列出当前记忆库中的物品，可按“有物体位置”“仅观察记录”“位置待确认”筛选。记忆库随当前地图自动切换，没有建图功能时使用默认库。仅观察记录只表示“在这里看见过”，不是物体坐标。

“区域”与“关系图”面板（语义地图）显示区域边界、名称与证据，以及区域、连接口与物品的关系。区域相邻不代表机器人可以直接通过，能否通行以导航检查为准；点“识别当前地图”触发一次语义识别（勾选“采用达标标签”时，本次识别采用证据达标的名称），“持续识别”开启后台周期识别，“停止识别”停止后台识别。

## 能力

“能力”视图列出智能体可用的全部能力，按地图、导航、探索、运动、记忆与语义、感知等分组，可按名称或说明搜索。选中一项后，页面按参数说明生成表单：必填项在前，下拉选择枚举和是否，数字与文字直接填写，结构化参数（如探索边界、停止条件）按 JSON 填写，可展开查看参数结构。留空的可选参数不发送，由能力使用默认值。

查询类能力直接显示返回内容；任务类能力显示进度并可取消，结束后显示结果；失败时显示后端给出的原因。会让机器人运动或删除数据的能力执行前会确认。这里的调用与智能体完全相同，新增的能力也会自动出现在列表中。

## 日志

“日志”视图按等级、来源（平台服务、Rust 运行进程、原生组件）、组件、全文、请求标识和任务标识筛选；“暂停更新”后可连续阅读和复制，“加载更早记录”翻页，“下载文本”或“下载结构化日志”导出当前筛选结果。导出内容可能包含设备信息和现场数据，分享前检查。

## 设置

“设置”分为三类：

- **软件更新**：检查更新、“更新并重启”，以及自动检查、空闲时自动安装和检查间隔。更新要求没有任务运行、没有正在进行的建图且运动已停止；不需要停用电机。
- **设备管理**：经管理页打开控制台时显示，返回设备管理页。
- **平台设置**：按功能分为机器人、视频与视觉识别、建图与定位、导航与探索、记忆与语义、人员跟随、操作设备、性能监控、日志、网页与接口等板块，左侧导航可直接跳到板块，搜索框可按名称、键名、说明或子类查找。功能的总开关在板块标题栏（例如视觉识别、性能监控、按需启动导航），子功能开关在子类标题栏（例如建图录制、语义地图）；开关点一下即保存，标“立即生效”的马上起作用，标“重启后生效”的会提示重启。其余参数按子类分组，常用项在前，高级项默认收起；修改后点“保存改动”，需要重启的项点“立即重启相关进程”。“另存为新方案…”复制方案，“设为运行方案”切换方案。

配置键与生效规则见[配置说明](配置说明.md)。不确定字段含义时先看说明，不要靠放宽限值掩盖接入错误。
