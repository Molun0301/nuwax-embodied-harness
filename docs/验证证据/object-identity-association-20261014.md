# 物体位置记忆与跨观察关联（2026-10-14）

## 修复对象

同一物体在不同时间、相机或视角再次出现时，应更新既有实例，而不是只因为二维图像中的位置变化、跟踪号变化或隔夜就新增实例。此次只修复关联、其必要的来源元数据和最终持久化；不删除或批量合并历史记录。

原路径已经用自然分配的 `instance_id` 执行 SQLite upsert 并在重启时加载。实际身份断裂来自关联阶段：跨图像比较像素中心、可移动物体 12 小时硬截止，以及只按类别设置较大米制半径。另发现同批多个来源关联同 ID 时，逐个提交中间结果会丢掉后续证据；旧 STATIC 记录没有短时窗口时，还可能被一次重见降为 UNKNOWN 并从持久库移除。

## 现在的规则

- 在相同地图坐标域内，使用可靠物体坐标、实际尺寸或可见点云范围、语义和可用外观属性关联
- 尺寸允许轴向中心偏差，另给最长已测跨度 10% 的尺度相关支持容差；这是启发式支持容差，不是传感器协方差或实机精度保证
- 可靠深度中心没有实体尺寸时，可以使用三角化米制残差或该测量深度处的观测视锥范围；这些范围不作为虚构尺寸传给渲染器
- 旧可靠点位可以由新的尺寸证据重新关联。双方都缺少尺寸、误差、视锥和跟踪证据时，仅凭抖动的孤立点无法可靠判定身份，保持保守
- 同相机、同定位会话、30 秒内的明确跟踪连续性支持已关联物体移动；移动物体使用最新接受位置，不拖着全生命周期平均位置
- 跨相机、重定位、重启或隔夜不再用图像像素位置/旧的 12 小时限制割裂可靠物体身份；临时动态对象仍有短期身份期限
- 同一来源、同一相机的检测一对一分配。明确同跟踪对象且几何/语义相容的 3D、2D 证据可共用身份，保留各自关联输出；缺失或不同跟踪号不据此合并
- 多候选按空间吻合度及语义/跟踪证据确定归属；同分历史重叠记录按首次出现时间及已有 ID 确定选择，其他历史记录保留
- 当前观察窗口或末次来源中仍有记录的重放不重复增加观察次数；同帧位置精化替换原贡献，不重复加权
- 同批同 ID 的最终完整结果只提交一次，所有输入关联和链接保留，SQLite 重新打开后次数及最新证据一致
- 自动老化与明确移除分开；自动老化可重见，重新激活清掉老化例外，明确移除不被后续老化循环偷偷恢复
- 旧持久 STATIC 记录在缺少短时窗口时，保留其已有静态结论，直到有足够的新运动证据

## 地图身份

复用现有 `AssetIdentityV2.asset_id`，不计算新的内容标识。已知资产 ID 不同，即使地图同名，也不能合并；资产 ID 相同允许来源 epoch、定位会话改变。显式拍照写入使用捕获定位快照中的身份，不借用后来的活动会话。临时缺少会话时，不清空记录中已经确认的资产 ID。

没有分配资产身份的历史路径仍按既有地图名称及坐标系兼容规则处理。仅凭运行时 `source_epoch` 无法判断是重启还是同名地图替换，这类旧数据仍有身份信息不足的边界。

## 实现和性能

`SpatialCandidateIndex` 是每批新建的单轴区间索引：选择物体分布较宽的轴，排序下界并保存前缀最大上界，查询后再检查其他两轴。规范尺寸只读成保守外接范围；精确旋转几何仅解析局部候选并在该批复用。改变的少量对象使用批内 overlay。没有跨批可变缓存、额外锁、新依赖或固定米制关联半径。

初版 BVH 在每批全量规范化尺寸并递归排序，对 2048 条历史、单检测的全调用中位数为 61.47 ms，因开销过大被替换。该失败方案的测量证据保留。

最终基准固定旧提交 `e1873185084b5bb51cec9328e57fae0493ceefc3`，Python 3.8.10，预热后 8 次，交替运行旧/新实现，使用双方均能正确关联的分离、同标签合成场景。计时包括索引建立、返回字典、模型更新和全量老化：

| 历史物体 | 当前检测 | 旧实现中位数 | 新实现中位数 |
| --- | --- | --- | --- |
| 32 | 1 | 0.59 ms | 0.87 ms |
| 32 | 16 | 8.01 ms | 8.87 ms |
| 2048 | 1 | 13.10 ms | 28.34 ms |
| 2048 | 16 | 156.00 ms | 31.91 ms |

2048 条历史时区间索引建立约 2.9 ms，候选打分为 1/16 次，旧实现为 2048/32648 次。单检测仍有每批边界处理的额外成本，不能把候选减少宣传为所有场景加速；新单检测最小耗时为 19.41 ms，测量有波动。大量相互覆盖的区间也会降低索引筛选效果。

可复现命令：

```bash
python -B scripts/diagnostics/benchmark_object_spatial_association.py --iterations 8
python -B -m pytest -q tests/unit/test_object_spatial_association.py tests/unit/test_memory_motion_reliability.py scripts/check_memory_embedder_cache.py -p no:cacheprovider
```

## 验证边界

关联专项 20 案例，加原有运动和嵌入缓存检查，总计 52 项通过。专项覆盖换相机/像素位置、隔夜、小幅位姿抖动、邻近杯子交替和重排、同帧一对一、跟踪移动及复用隔离、地图/坐标系/资产隔离、回退位置、点位/视锥/残差、来源重放、多来源同 ID、自动老化/明确移除、历史重复记录保留、2000 物体局部候选、颜色区别、非有限位置、配对模态以及大型细长物体/精确边界。

另有独立真实 MemoryService + SQLite 接受测试验证重启、捕获快照、同批最终状态及公共查询；尺寸/界面验证记录见 `object-extent-rendering-20261014.md`。

这些是无设备、无外部模型的合成输入与实际存储/服务测试，没有实机或现场传感器验证。位置和标签都不可区分的邻近物品不能获得身份保证；完整物体尺寸也不能由部分可见点自动补全。既有重复记录不会被这次修复自动删掉或重写为一个对象。
