# 发布与兼容性

Nuwax Embodied Harness（NEH，具身运行框架）当前是**开发预览**，以不同机器人接入和受控场景验证为主要用途。本页状态核对于2026年9月29日，不代表正式稳定版或完整设备认证。

## 获取哪个版本

当前开发分支是 `refactor/map-explore-nav`，默认分支 `main`（主分支）仍是历史实现。下载时显式选择开发分支，并使用同分支的文档、安装脚本和源码。

目前没有正式发布包或稳定版本的兼容承诺。协议中的内部版本、分支上的提交或算法归档标签，都不应被当作已经完成产品验收的发行版。

## 本轮产品包装变化

- 产品及公开网页名称统一为 Nuwax Embodied Harness，简称 NEH。
- 仓库改名为 [Molun0301/nuwax-embodied-harness](https://github.com/Molun0301/nuwax-embodied-harness)，保持私有。
- 安装向导增加用途说明与基础、二维、三维方案；环境检查返回实际缺项和退出状态。
- 全新模块安装默认监听本机，安装完成给出配置、启动和设备接入指引。
- 文档补齐准备、配置、控制台、升级恢复、排障、数据与贡献流程。

这些变化属于产品交付准备，不代表所有机器人和算法场景都已验收。

## 支持与边界

| 范围 | 当前结论 |
| --- | --- |
| 本机模块安装 | Debian/Ubuntu系列、64位主机、Python（编程语言）3.8—3.12；具体组合仍按实际依赖验证 |
| 基础控制台与接口 | 可独立安装；标准输入由设备接入方提供 |
| Go2（宇树四足机器人） | 有实际设备接入与已有部署更新入口；厂商依赖和交叉环境需单独准备 |
| 其它机器人 | 提供标准装配与接口；每种设备的标定、执行与功能需接入验收 |
| 二维链路 | 有实现与本地验证，设备现场表现需单独确认 |
| 三维导航与探索 | 有实现、回放和部分实机证据；复杂地图计算长尾、场景稳定性及完整覆盖仍待完善 |
| 语义地图 | 实验能力；真实环境用途识别和导航闭环不作普遍承诺 |
| 档案生产安装 | `go2-jetson` 仍有待完成的依赖锁与制品，未标记为可部署 |
| 网络与权限 | 宿主机网关没有完整账号鉴权，部署方需提供访问边界 |
| 许可证 | 项目级许可待定，当前不声明开源或商业再分发授权 |

## 名称兼容

以下内部名称继续使用，不能做全仓库字符串替换：

| 保留内容 | 示例与原因 |
| --- | --- |
| Python/Rust（编程语言）包和程序 | `nuwax-*`、`nuwax_robot_bridge`；避免改变导入和构建 |
| 环境变量 | `NUWAX_*`、设备专用键；已有配置继续可读 |
| 协议与工具身份 | 消息通道、响应字段和协议服务器名称；避免破坏客户端 |
| 系统服务与数据目录 | `nuwax-host-gateway`、`/var/lib/nuwax_robot_bridge/`；避免影响运行部署 |
| 已有源码目录 | `/home/unitree/nuwax-robot-bridge` 等实际路径；仓库改名不会移动设备文件 |

旧克隆可在仓库根更新自己的远端地址，HTTPS或SSH（安全远程连接）任选与现有认证方式一致的一种：

```bash
git remote set-url origin https://github.com/Molun0301/nuwax-embodied-harness.git
```

设备路径与系统服务不随该命令改名。合作方和自动化配置中的仓库链接也需核对。
