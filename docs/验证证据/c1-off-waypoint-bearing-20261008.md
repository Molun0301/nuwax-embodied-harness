# C1 OFF 稀疏路径点方位修正（2026-10-08）

基准：`9c8e535ac75cb0976b28415b78162cac9416f210`。本次只发布候选 A：一个执行条件修正和一个机体控制单测；不包含候选 B、软代价反馈或原生模拟器变更。

## 根因与改动

局部规划 OFF 直接跟随 PCT 稀疏参考。旧条件允许“入段切向与机体朝向误差小于 0.6 rad”代替“实际目标方位与机体朝向误差小于 0.6 rad”。目标仍在机体侧后方时也可能开始平移，随后又转回原地转向，形成转向/微位移循环。

`surface_body_control.rs` 的唯一生产修改是把切向对齐分支限定为 `local_planning_enabled`。OFF 可原地转向时，开始平移仍须满足原有的实际目标方位阈值；不能原地转向时仍沿原逻辑执行。ON 的布尔条件等价于原实现。速度、运动接口、扫描预算、净空和扫掠守卫均未修改。

新增 `off_sparse_corner_turns_toward_actual_waypoint_before_translation`：入段切向已经对齐，但实际目标仍在侧后方时，要求先转向实际目标，不能立即平移。
