# 功能介绍

Nuwax Robot Bridge 将机器人对环境的观察、对空间的表达和实际任务执行组织在同一个平台中。它适合搭建机器人实验系统、室内空间感知应用，以及由上层智能体编排的移动任务。

本文对应当前源码。具体设备可用的能力由传感器、已安装模块、配置与运行状态共同决定。

按模块查看逐项实现状态、未实现入口和近期验证边界，见[项目功能与实现情况清单](项目功能与实现情况清单.md)。

## 地图与定位

### 两条完整链路

| 链路 | 输入与算法 | 适用的空间表达 |
| --- | --- | --- |
| 二维激光链 `slam_2d` | 规范二维扫描与所需里程计；二维建图、图定位、波前探索和二维导航 | 平面占据栅格与完整二维图资产 |
| 三维激光惯性链 `lio_3d` | 三维点云、IMU（惯性测量单元）及标定；FastLIO2（快速激光惯性里程计）或 PointLIO（逐点激光惯性里程计） | 三维点云、多层支撑表面及水平扫描投影 |

链路配置同时决定建图、探索与导航的组合。切换网页的二维或三维视角，只改变展示方式。

三维前端共用关键帧管理、地点检索、回环配准和位姿图优化。系统在确认回环后重建历史地图，并协调更新地图与定位关系。原理和使用条件见[双 LIO 建图与回环纠偏](双LIO建图与回环纠偏.md)。

### 地图作为长期资产

地图管理涵盖创建、保存、激活、删除、重定位和续建。地图工作区绑定同名记忆库，让几何信息和观察记录处于同一环境范围内。

保存资产可包含栅格、点云、后端检查点和完整扫描数据。恢复时依赖对应资产：一张可显示的栅格图片，并不自动具备图定位或继续建图所需的数据。旧资产缺少完整扫描时，控制台会显示相应限制。

### 多种视图

控制台支持二维栅格、三维点云和语义地图，并可显示轨迹、物品与禁行区。三维视图包含高度样式和完整点云；完整点云分块读取已接纳的扫描点，保留原坐标与重复观测，支持增量更新。

三维建图的二维投影来自雷达附近高度的水平扫描切片。它适合观察平面轮廓，低矮障碍、悬空物与机体净空仍需三维信息判断。

## 导航与探索

### 前往明确目标

可以从控制台选择地图目标，也可以通过工具前往坐标、命名地点或有效记忆候选。任务提供受理、运行、到达、失败与取消反馈。

二维导航依据平面地图与机器人外形规划；三维导航依据 MLS（多层表面）中的支撑、坡度、台阶和净空约束规划。后者还要求真实机体尺寸、机体到支撑面的距离及底层设备运动能力。

禁行区可在地图中编辑，二维和三维视图复用相同业务入口；三维视图支持多种形状。导航、探索与跟随发出的运动意图统一经过运动守卫。

### 探索未知区域

探索可按半径或边界寻找未知区域，结合当前可通行信息选择观察位置，再通过导航执行。单层探索还提供：

- 按行程与时限设置任务预算，按所选策略返航。
- 暂停后先停车，再保存地图和探索进度。
- 从完整检查点恢复，重新定位并重新检查执行条件。
- 查询任务阶段、已行进距离、保存结果与具体阻塞原因。

“任务已受理”可能仍在等待输入；没有选择出可行目标时，机器人不会因为任务处于运行状态就开始移动。暂停完成、地图保存完成和实际停车分别确认。

平台也有楼宇地图、设施与跨层任务编排入口。它们依赖已登记连接、有效目标地图和实际设备能力，当前不作通用自主上下楼或跨楼层任务的实机保证。

## 视觉感知与人物跟随

图像可以用于实时观察、抓拍或模型推理。感知管线支持目标检测、跟踪、可选分割，以及结合相机标定、深度或点云的空间估计。已有 YOLO-World（开放词汇目标检测模型）等后端接入；实际类别范围取决于使用的模型和导出引擎。

持续感知按配置处理新观察和关键帧，向控制台与记忆服务发布结果。视频显示帧率、检测频率和记忆写入频率各有独立含义。

人物跟随复用视觉、导航与运动链。目前的目标选择仍有局限，不承诺复杂遮挡下持续识别同一具体人物。

## 空间记忆

记忆服务把“看见了什么”“在哪里看见”“有什么图像依据”关联到当前地图。主要内容包括：

| 记录 | 用途 |
| --- | --- |
| 命名地点 | 保存门口、工作台等已知位置 |
| 场景摘要与观察事件 | 检索某次场景，并追溯时间与图像 |
| 物品实例 | 关联多次观察，维护位置与生命周期 |
| 场景区域和空间关系 | 组织区域、连接口、物品及证据 |
| 导航候选 | 将具备有效空间依据的记录交给导航进一步检查 |

支持文本与图像向量检索，具体模型可按配置采用本地或远端方案。记录带有地图归属、来源和空间质量信息。只有观察者位置、缺乏物体几何依据的记录会标为“仅观察”，不会直接当作物体坐标导航。

到达某个记忆位置后，可以再次获取图像或感知结果，复核物品是否仍在。检索匹配、导航到达和视觉确认是三个不同结果。

## 语义地图与空间关系图

这部分是当前新增的实验能力。平台从几何地图中提取区域候选，选择相关观察证据，再通过配置的模型提出区域用途或名称候选。

已接入 Jev（决策服务）的远端文本接口和 OpenJev（本地图文决策模型）的独立服务接口。默认关闭语义建图，也不自动采用标签；启用自动采用后仍需满足多视角与一致性等证据条件。显式修改的名称受到保护。

控制台可查看精确区域边界、名称候选、证据与修订，并浏览区域、连接口、物品和观察构成的关系图。智能体可查询节点与邻接关系，导出带编号的地图图像，或获取区域之间的候选连接路线。

区域连接路线只表达几何关系，尚未检查机器人实际通行。几何区域也不等于已识别出真实房间；当前高度归属与现场用途识别仍有待验证。

## 控制台与开放接口

[控制台](http://127.0.0.1:8766/console)将地图、视频、任务、记忆、日志与配置放在同一界面，支持桌面与窄屏布局、明暗主题及三维交互。

设置支持按机器人管理多个方案，查看配置来源、默认值、已读取值与生效范围，并选择保存后立即或稍后重启。结构化日志支持筛选、任务关联与导出。

MCP（模型上下文协议）、HTTP（超文本传输协议）接口和网页复用公共能力与任务执行。地图、视频和状态通过数据流更新；网页断线不会自动取消已受理任务。接入方法见[智能体接入](智能体接入.md)。

## 使用与验证边界

| 范围 | 当前说明 |
| --- | --- |
| Go2（宇树四足机器人） | 有设备接入及建图、视频等现场使用记录；具体导航、探索和地图精度仍需按版本与场景验收 |
| 通用设备与二维雷达 | 标准数据入口、二维完整链及思岚 S2 驱动已有实现；二维现场运动和目标板表现仍待验收 |
| 三维导航与探索 | 已有支撑、净空与规划执行链；真实复杂地图仍存在可行路线与输入质量限制 |
| 语义地图 | 本地模型与几何、观察、标签、存储链已接通；真实用途识别、多楼层归属及区域导航闭环未完成验收 |
| 识别与检索 | 需要真实模型、适当词表和观察；离线替代表示只能验证流程 |
| 性能与精度 | 没有适用于所有设备的固定帧率、延迟或厘米级精度承诺 |

当前重点是完善真实场景下的建图、探索导航与语义证据闭环。机械臂操作、多机器人协作和完整的自主采购等任务，不在本文的现有能力承诺内。
