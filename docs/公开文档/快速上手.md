# 快速上手

本指南带你安装基础环境、打开控制台，并了解第一次建图与任务调用的顺序。所有命令都在仓库根目录执行。

## 1. 安装所需模块

本机模块安装支持 Debian、Ubuntu（操作系统）系列环境，使用 Python（编程语言）3.8—3.12。以普通用户运行；安装系统依赖时可能需要管理员权限。

```bash
./install.sh
```

安装器会展示硬件信息、推荐模块和依赖。回车接受当前方案，也可以按编号调整。想先了解将安装哪些内容，可以只查看计划：

```bash
./install.sh install --dry-run
```

初次体验可以只安装基础网关：

```bash
./install.sh install --modules core --yes
```

这会提供控制台、接口与标准接入环境。没有接入设备时，状态和画面会显示相应的等待或不可用原因。

需要增加功能时，按设备条件选择模块。以下命令分别是可选操作：

```bash
# 三维激光惯性建图，选择一个定位前端
./install.sh add fastlio2

# 在已有三维链路上增加导航与探索
./install.sh add navigation

# 增加本地视觉与本地语义记忆模型
./install.sh add perception memory
```

二维雷达选择 `slam2d`，与 `fastlio2`、`pointlio` 互斥。模块说明及完整选择示例见[部署指南](部署文档.md)。

## 2. 配置并连接设备

查看当前安装和设置位置：

```bash
./install.sh list
```

模块安装使用自己的配置文件。按照输出路径配置机器人类型、设备连接、传感器和标定，再启动：

```bash
./install.sh start
```

该命令在前台运行，按 `Ctrl+C` 停止。打开 [机器人控制台](http://127.0.0.1:8766/console)；从其他电脑访问时，将地址中的 `127.0.0.1` 换成网关所在主机的地址。

在控制台检查实际数据：状态是否更新、相机是否收到画面、雷达与惯性输入是否到达。需要修改参数时进入设置页，按机器人选择方案，并根据页面提示应用或重启。

如果使用的是自己的机器人，按照[架构与机器人接入](架构与机器人接入.md)发布标准数据并绑定执行器。安装模块本身不会生成设备数据或完成标定。

## 3. 完成一次建图

确认所选链路的输入和程序可用后，在控制台进行：

1. 创建并选择一个有明确名称的地图工作区。
2. 启动建图，检查有效定位与地图是否持续更新。
3. 在实际设备允许的控制方式下采集环境，观察轨迹与地图轮廓。
4. 结束本次采集并保存地图，查看保存结果与资产状态。
5. 再次使用时激活已保存地图，并按返回状态完成定位或重定位。

二维地图适合看平面轮廓，三维视图适合看高度、支撑与完整空间结构。使用三维链路时，切换到二维视图不会改变导航算法。

保存地图与停止建图是不同操作，按各自回执确认。需要续建时还须具备对应后端检查点；已有地图图片不能代替完整资产。

## 4. 使用导航、探索和记忆

**导航：**在已定位的目标地图中选点，检查目标位置后发起任务。选点导航只要求到达位置；通过接口显式指定朝向时，才检查最终朝向。三维视图选点应落在实际地面，并已配置机体到支撑面的距离。观察任务的最终结果，而不仅是“已受理”。

**探索：**根据场地设置边界和预算，发起探索并查看是否已选出可行目标。需要中断并保留进度时，使用暂停并保存，等待停车和检查点结果；恢复会重新定位并检查条件。

**感知与记忆：**启用已配置模型的感知，查看检测结果和物品列表。记忆绑定当前地图；只有观察位置的记录会保留“仅观察”含义。语义地图另需启用并配置决策服务，当前为实验能力。

这些功能的依赖与限制见[功能介绍](功能列表.md)。

## 5. 连接应用或智能体

网关运行后，可以只读检查状态和接口目录：

```bash
curl -fsS http://127.0.0.1:8766/api/health
curl -fsS http://127.0.0.1:8766/api/agent/tools
```

MCP（模型上下文协议）入口是 `http://127.0.0.1:8766/mcp`。也可以使用只依赖 Python 标准库的客户端：

```bash
python3 clients/robot_client.py --url http://127.0.0.1:8766 info
python3 clients/robot_client.py --url http://127.0.0.1:8766 tools
```

健康接口成功表示网关可响应。建图、导航或识别是否可用，还需查看各自的输入与任务结果。调用方法见[智能体接入](智能体接入.md)。

## 没有机器人时验证基础流程

在已经安装项目依赖的 Python 环境中，可以运行离线检查：

```bash
python3 scripts/diagnostics/offline_platform_smoke.py
```

它使用模拟的静止状态和图像，启动真实本机网关，检查能力发现、抓图、制品读取、感知编排和地图创建等流程，然后关闭进程。不连接机器人，也不下载或加载识别模型。

这项检查适合确认软件接线，实机运动、模型识别与建图精度需分别验证。若使用模块安装，先通过 `./install.sh list` 找到当前安装目录，再使用该目录内的 `venv/bin/python` 执行脚本。
