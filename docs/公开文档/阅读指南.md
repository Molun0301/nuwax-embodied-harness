# 公开文档阅读指南

Nuwax Robot Bridge 为机器人提供地图、感知、空间记忆与运动任务能力，并通过浏览器和智能体接口供外部使用。

如果是第一次接触项目，先读[项目首页](../../README.md)，再根据你要做的事选择下列文档。

| 你想了解什么 | 阅读入口 |
| --- | --- |
| 项目现在能做什么，适合哪些场景 | [功能介绍](功能列表.md) |
| 安装、打开控制台、完成第一次使用 | [快速上手](快速上手.md) |
| 选择安装模块、配置服务、更新已有 Go2 | [部署指南](部署文档.md) |
| 让智能体或应用调用机器人 | [智能体接入](智能体接入.md) |
| 直接使用面向 Go2 的任务提示词 | [Go2 提示词示例](Go2提示词示例.md) |
| 理解系统分工，接入自己的机器人 | [架构与机器人接入](架构与机器人接入.md) |
| 理解两种三维定位前端与回环纠偏 | [双 LIO 建图与回环纠偏](双LIO建图与回环纠偏.md) |

文档以当前源码为依据。工具名称与参数以所连接网关的实际发现结果为准，设置以控制台的配置目录为准。功能说明中的“已实现”表示存在对应实现，不代表每种设备与环境都完成了现场验收。

历史调研报告记录当时的技术分析，不作为当前安装步骤或功能清单。
