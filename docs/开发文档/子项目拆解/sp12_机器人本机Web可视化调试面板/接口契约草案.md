# 接口契约草案：sp12 机器人本机 Web 可视化调试面板

## 1. 契约定位

1. sp12 是机器人本机 Web（网页）只读可视化调试面板，不是控制面。
2. 后端只提供 read-only aggregation（只读聚合）能力，把现有状态、日志、地图、定位、探索、点云数据整理成前端可消费的数据模型。
3. 不复制建图、定位、导航、探索逻辑，不创建平行 geometry（几何）主链。
4. 不绕过现有调用边界：`PlatformGeometryRuntime -> MappingService / LocalizationService / NavigationService`。
5. Go2 DDS（数据分发服务）或 provider（提供器）点云只能作为只读可视化数据源，不能承担平台 geometry 主链职责。
6. 所有接口默认只允许 `GET` 或只读 WebSocket（网页套接字）事件流。
7. 接口必须明确表达数据缺失、过期、错误和坐标系不可用，前端不得伪造数据。

## 2. 明确禁止项

MVP（最小可行产品）禁止提供或间接暴露以下能力：

1. 机器人运动控制接口。
2. 导航目标下发接口。
3. 探索启动、暂停、恢复、停止接口。
4. 地图保存、删除、清空、重定位等修改型接口。
5. 任意文件读取接口，包括通过日志、静态资源或参数拼接读取非授权路径。
6. 任意 ROS service/action（机器人操作系统服务/动作）调用代理。
7. 任意 DDS 写入、ROS topic（话题）发布或运行时配置修改。
8. `POST`、`PATCH`、`DELETE` 类控制接口进入 sp12 MVP。

## 3. 统一观测信封

所有 HTTP（超文本传输协议）响应和 WebSocket 事件都使用统一观测字段。具体业务负载放在 `data` 中。

```json
{
  "ok": true,
  "type": "map.frame",
  "source": "mapping_service",
  "frame_id": "map",
  "source_timestamp": "2026-04-27T10:00:00.000Z",
  "gateway_timestamp": "2026-04-27T10:00:00.120Z",
  "sequence": 42,
  "revision": "mapv_default_42",
  "frequency_hz": 5.0,
  "latency_ms": 120,
  "stale": false,
  "status": "available",
  "data": {},
  "error": null
}
```

| 字段 | 必需 | 含义 |
| --- | --- | --- |
| `ok` | 是 | 本次读取或事件生成是否成功 |
| `type` | 是 | 负载类型，例如 `snapshot`、`map.frame`、`pointcloud.frame` |
| `source` | 是 | 只读数据来源，例如 `mapping_service`、`localization_service`、`navigation_service`、`go2_provider` |
| `frame_id` | 坐标数据必需 | 数据所在 frame（坐标系）；无坐标数据时为 `null` |
| `source_timestamp` | 是 | 数据源采集或生成时间 |
| `gateway_timestamp` | 是 | 网关聚合并返回或推送的时间 |
| `sequence` | 可选 | 单调递增序号，适合日志、位姿、点云等连续数据 |
| `revision` | 可选 | 快照版本，适合地图、frontier 等可替换图层 |
| `frequency_hz` | 可选 | 数据源或后端观测到的更新频率 |
| `latency_ms` | 是 | `gateway_timestamp - source_timestamp`，用于端到端观测 |
| `stale` | 是 | 数据是否超过该类型的过期阈值 |
| `status` | 是 | `available`、`missing`、`stale`、`error`、`unsupported` |
| `data` | 是 | 业务负载；不可用时可为 `null` 或空结构 |
| `error` | 是 | 错误码、错误消息和可展示原因；成功时为 `null` |

## 4. 错误语义

| 错误码 | 含义 | UI（用户界面）处理 |
| --- | --- | --- |
| `source_unavailable` | 数据源不可用 | 显示缺失状态和最近更新时间 |
| `source_stale` | 数据过期 | 保留最后一帧并标记 stale（过期） |
| `frame_missing` | 缺少坐标系 | 不叠加到地图或点云 |
| `transform_unavailable` | 坐标变换不可用 | 显示坐标警告，不自行推断 |
| `payload_too_large` | 响应或帧过大 | 提示可选保护配置，不默认丢弃数据 |
| `unsupported` | 当前真机链路不支持该数据 | 显示不可用原因，不阻塞其他图层 |
| `internal_error` | 服务内部错误 | 显示错误摘要和来源 |

## 5. 只读 HTTP 接口

### 5.1 页面入口

`GET /debug/`

用途：打开机器人本机 Web 调试面板。

要求：页面不包含控制按钮，不触发任何控制型请求。

### 5.2 聚合快照

`GET /api/debug/snapshot`

用途：一次读取面板首屏所需的轻量快照，适合页面初始化和重连恢复。

响应 `data` 草案：

```json
{
  "health": {"status": "available"},
  "map": {"revision": "mapv_default_42"},
  "pose": {"sequence": 1201},
  "trajectory": {"revision": "traj_1201"},
  "frontiers": {"revision": "frontiers_88"},
  "pointcloud": {"sequence": 9012},
  "video": {"sequence": 9013},
  "logs": {"next_cursor": 20480}
}
```

### 5.3 日志 tail

`GET /api/debug/logs/tail?cursor=<cursor>&limit=200&level=info&source=gateway`

用途：按 byte offset cursor（字节偏移游标）增量读取配置日志文件 `runtime.config.logging.log_file` 的近期日志。接口只读取网关配置中的日志路径，不能把路径参数映射为任意文件读取。

响应 `data` 草案：

```json
{
  "next_cursor": 20480,
  "entries": [
    {
      "sequence": 1001,
      "timestamp": "2026-04-27T10:00:00.000Z",
      "level": "info",
      "source": "gateway",
      "message": "service started"
    }
  ],
  "metrics": {
    "auth_ms": 0.2,
    "path_resolve_ms": 0.1,
    "file_stat_ms": 0.1,
    "file_read_ms": 1.4,
    "bytes_read": 8192,
    "raw_lines": 40,
    "server_compute_ms": 2.1
  }
}
```

要求：普通 tail 是立即返回的 GET（读取）接口，不做长轮询。若后续需要实时日志流，应新增 SSE（服务器发送事件）或 WebSocket（网页套接字）流，并把连接驻留时间和普通请求耗时分开观测。

### 5.4 地图帧

`GET /api/debug/map/frame/latest`

用途：读取最新 2D SLAM（同步定位与建图）占据栅格帧。数据来源必须经过 `PlatformGeometryRuntime -> MappingService`。

响应 `data` 草案：

```json
{
  "map_id": "mapv_default_42",
  "resolution_m": 0.05,
  "width": 400,
  "height": 300,
  "origin": {"x": -10.0, "y": -7.5, "yaw_rad": 0.0},
  "encoding": "occupancy_int8",
  "cells": "base64-or-artifact-ref",
  "legend": {
    "unknown": -1,
    "free": 0,
    "occupied": 100
  }
}
```

要求：地图端到端刷新延迟 P95（第 95 百分位延迟）目标小于 1 秒。

### 5.5 当前位姿帧

`GET /api/debug/localization/pose/latest`

用途：读取机器人当前位姿。数据来源必须经过 `PlatformGeometryRuntime -> LocalizationService`。

响应 `data` 草案：

```json
{
  "pose": {
    "x": 1.2,
    "y": 0.4,
    "z": 0.0,
    "yaw_rad": 1.57
  },
  "covariance": null
}
```

### 5.6 轨迹帧

`GET /api/debug/localization/trajectory?since=<timestamp>&limit=2000`

用途：读取机器人位姿历史，来源为定位历史缓存或运行态轨迹缓存，不重新实现轨迹推算。

响应 `data` 草案：

```json
{
  "points": [
    {
      "x": 1.0,
      "y": 0.2,
      "z": 0.0,
      "yaw_rad": 1.4,
      "timestamp": "2026-04-27T10:00:00.000Z"
    }
  ]
}
```

### 5.7 frontier 帧

`GET /api/debug/exploration/frontier/latest`

用途：读取最新 frontier（探索前沿）图层。数据来源必须经过 `PlatformGeometryRuntime -> NavigationService` 或其已暴露的探索状态，不在 sp12 中重新计算导航逻辑。

响应 `data` 草案：

```json
{
  "frontiers": [
    {
      "id": "frontier_001",
      "geometry": {
        "type": "point",
        "coordinates": [2.0, 1.5, 0.0]
      },
      "score": 0.82,
      "metadata": {}
    }
  ]
}
```

要求：frontier 端到端刷新延迟 P95 目标小于 1 秒。

### 5.8 点云地图主视图

`GET /api/debug/pointcloud-map/latest/meta`
`GET /api/debug/pointcloud-map/latest.bin?lod=<level>&revision=<revision>`

用途：读取累计扫描形成的 3D（三维）点云地图。该接口是 Web 主 3D 点云地图视图的正式数据源，不能回退到最新扫描帧。

数据来源优先级：

1. 在线 RTAB-Map（实时外观建图）累计地图云。
2. 当前激活地图版本的 `MapVersion.geometry_asset.pcd_path`。
3. 平台 RTAB-Map PCD（点云数据文件）根目录下的受管 `cloud_map.pcd`。

`meta` 响应 `data` 草案：

```json
{
  "map_name": "office",
  "map_version_id": "mapv_default_42",
  "revision": "pcd:mtime:size",
  "frame_id": "map",
  "source": "map_version_pcd",
  "geometry_stack": "rtabmap_nav2",
  "rtabmap_db_path": "/path/to/rtabmap.db",
  "pcd_path": "/path/to/cloud_map.pcd",
  "point_count": 420000,
  "bounds": {"min": [-4.0, -3.0, -0.3], "max": [6.0, 5.0, 1.8]},
  "lods": [
    {"level": "preview", "point_count": 50000, "bin_url": "/api/debug/pointcloud-map/latest.bin?lod=preview&revision=pcd:mtime:size"},
    {"level": "full", "point_count": 420000, "bin_url": "/api/debug/pointcloud-map/latest.bin?lod=full&revision=pcd:mtime:size"}
  ],
  "metrics": {
    "server_compute_ms": 12.4,
    "payload_bytes": 0
  }
}
```

要求：

1. `latest.bin` 使用二进制 `float32 xyz` 或后续正式二进制封装，前端以 `ArrayBuffer` 读取。
2. `revision` 未变化时，前端不得重复下载同一份点云地图数据。
3. 累计地图不可用时返回 `missing/source_unavailable`，并给出当前激活地图、期望 PCD 路径和 RTAB-Map profile 摘要。
4. 不允许用 `/api/debug/pointcloud/latest` 的最新扫描帧作为本接口 fallback（回退路径）。
5. 当前实现支持 ASCII（文本）与 binary（二进制）PCD 的 `x/y/z` 字段；`binary_compressed` 必须显式返回 `unsupported_pcd_format`，不能静默回退为扫描帧。

### 5.9 点云实时帧诊断

`GET /api/debug/pointcloud/latest`
`GET /api/debug/pointcloud/frame/latest`
`GET /api/debug/pointcloud/frame/latest/meta`

用途：读取最新 3D 扫描帧，用于诊断传感器输入、DDS（数据分发服务）点云链路和 SLAM（同步定位与建图）输入质量。该接口不是点云地图主视图，不能代表累计地图。

响应 `data` 草案：

```json
{
  "pointcloud_id": "pc_001",
  "frame_id": "world/fake_go2/lidar",
  "source": "go2_pointcloud_provider",
  "point_count": 180000,
  "fields": [
    {"name": "x", "datatype": "float32"},
    {"name": "y", "datatype": "float32"},
    {"name": "z", "datatype": "float32"}
  ],
  "points": [
    {"x": 0.0, "y": 0.0, "z": 0.0},
    {"x": 1.0, "y": 0.2, "z": 0.1}
  ],
  "format": "xyz",
  "backend_fps": 12.5,
  "browser_fps": null,
  "render_ms": null,
  "payload_bytes": 2880000,
  "artifact_ref": null,
  "data_uri": null,
  "protection": {
    "default_max_points_applied_by_debug_api": false,
    "not_a_pointcloud_map": true
  },
  "metrics": {
    "inline_points": 180000
  }
}
```

说明：MVP 不预设强制限频、强制降采样或强制最大点数。接口可以暴露可选保护配置状态和观测指标，但默认不得把保护项作为数据可用前置条件。若真机点云过大导致页面不可用，再按验收数据评估可选保护配置。

### 5.10 视频实时帧

`GET /api/debug/video/latest`
`GET /api/debug/video/frame/latest`

用途：历史 HTTP（超文本传输协议）最新帧入口已迁移到实时流式链路；当前只返回 410 迁移提示。监控页不再通过该接口轮询图像，也不触发 `ImageProvider.capture_image()`。

当前正式链路：

1. Go2 端侧 `go2_video_streamer` 主动连接 `/streams/video.ingest`，连续推送 JPEG 帧。
2. 平台只接收、latest-only 缓存并通过 `/streams/video.mjpeg` 转发 MJPEG（Motion JPEG，动态图像串流）。
3. `/streams/ws` 的 `video.frame` 事件只承载状态、尺寸、`stream_url`、`payload_bytes`、`ingest_status` 等元数据，不承载图像字节。
4. 监控页使用 `fetch()` 读取 `/streams/video.mjpeg` 字节流，解析 JPEG SOI/EOI（图像开始/结束标记），用浏览器 JPEG 解码能力验证后替换 `<img>` 当前帧。
5. `rendered_frames` 表示浏览器实际解码并显示的 JPEG 帧数，不允许由 `video.frame` 元数据自增。

`video.frame` 事件 `data` 草案：

```json
{
  "camera_id": "front",
  "frame_id": "camera/front",
  "width_px": 1280,
  "height_px": 720,
  "encoding": "jpeg",
  "transport": "mjpeg",
  "stream_url": "/streams/video.mjpeg?camera_id=front_camera",
  "payload_bytes": 104857,
  "ingest_status": {
    "connected": true,
    "available": true,
    "fps_estimate": 15.0,
    "last_client_id": "go2-video-..."
  }
}
```

说明：若 `stream_url` 不可用，页面展示明确空态；若 MJPEG 字节流断开，页面必须基于前端解码状态重连，不能仅凭 `ingest_fps` 或 `payload_bytes` 判断画面已显示。

## 6. 只读 WebSocket 事件

`GET /api/debug/ws`

用途：推送面板实时更新。连接只允许订阅，不接受任何控制命令。客户端消息仅允许订阅过滤条件，例如事件类型白名单；禁止携带 ROS service/action、文件路径、运动目标或配置修改参数。

| 事件类型 | 含义 | 推荐负载 |
| --- | --- | --- |
| `snapshot` | 首帧或重连后的聚合快照 | 与 `/api/debug/snapshot` 一致 |
| `logs.tail` | 新日志可读或日志增量 | 日志 entries 与 next_cursor |
| `map.frame` | 2D 地图帧更新 | 地图 frame 或 revision 引用 |
| `localization.pose` | 当前位姿更新 | pose |
| `localization.trajectory` | 轨迹更新 | points 或 revision 引用 |
| `exploration.frontier` | frontier 图层更新 | frontiers |
| `pointcloud.frame` | 点云帧更新 | 点云 points、元数据、性能观测或引用 |
| `video.frame` | 视频状态与 MJPEG 转发入口更新 | `stream_url`、encoding、width/height、payload_bytes、ingest_status；图像字节由 `/streams/video.mjpeg` 承载 |
| `health.data-source` | 数据源健康更新 | sources |
| `source.error` | 数据源错误 | error 与 source |

点云帧可以使用 WebSocket 二进制帧或只读 artifact（制品）引用，但 artifact 引用必须由后端生成且绑定授权范围，不能由前端传入任意路径。

## 7. 点云可选保护配置与观测

点云默认展示真实本机数据压力，不强制启用以下保护项：

1. 限频。
2. voxel（体素）降采样。
3. 最大点数上限。
4. 暂停渲染。

允许接口暴露以下只读观测字段，供真机验收和后续判断是否需要手动保护：

| 字段 | 含义 |
| --- | --- |
| `point_count` | 当前帧点数 |
| `backend_fps` | 后端点云帧率 |
| `browser_fps` | 浏览器渲染 FPS（每秒帧数） |
| `render_ms` | 浏览器渲染耗时 |
| `payload_bytes` | 当前帧载荷大小 |
| `latency_ms` | 点云端到端延迟 |
| `dropped_frames` | 观测到的丢帧数量 |
| `protection_enabled` | 是否手动启用了保护配置 |

## 8. 前端数据模型要求

1. 所有图层都必须读取统一观测信封中的 `status`、`stale`、`source_timestamp`、`gateway_timestamp`、`latency_ms`。
2. 地图、位姿、轨迹、frontier、点云渲染前必须检查 `frame_id`；视频若有 `frame_id` 则展示来源。
3. frame 不一致或 transform（坐标变换）不可用时，前端显示警告，不自行猜测坐标变换。
4. 数据缺失时显示明确空态和原因，不使用假数据填充。
5. 日志面板只能展示聚合日志 entries，不允许提供文件路径输入。
6. 面板刷新、重连或订阅事件不得触发机器人动作。

## 9. 实现边界检查清单

- [ ] 仅新增或调用只读 `GET`/WebSocket 订阅接口。
- [ ] 未新增运动、导航、探索、地图修改能力。
- [ ] 未暴露任意文件读取。
- [ ] 未暴露任意 ROS service/action 代理。
- [ ] 地图数据经过 `MappingService`。
- [ ] 位姿与轨迹数据经过 `LocalizationService`。
- [ ] frontier 数据经过 `NavigationService` 或其探索状态输出。
- [ ] Go2 DDS/provider 点云只作为只读可视化输入。
- [ ] 点云没有默认强制限频、降采样或最大点数。
- [ ] 所有响应和事件都有统一观测字段。
