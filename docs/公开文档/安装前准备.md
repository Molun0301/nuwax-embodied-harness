# 安装前准备

本页适用于 Nuwax Embodied Harness（NEH，具身运行框架）的本机源码安装。NEH 可先安装在开发电脑上做标准设备接入，也可在具备条件的机器人计算机上运行。

## 选择机器

| 项目 | 当前要求或建议 |
| --- | --- |
| 系统 | 自动安装面向 Debian、Ubuntu 及相应衍生系统；建议先在 Ubuntu 22.04/24.04 开发机验证 |
| 架构 | `x86_64` 或 `aarch64`（64位ARM架构）；32位系统不在当前自动安装范围 |
| Python（编程语言） | 3.8—3.12；安装器检查真实解释器，不只看文件名 |
| 用户权限 | 普通用户运行安装器；缺少系统包时需要 `sudo`（管理员提权工具） |
| 网络 | 系统软件源、Python包源可达；原生算法、推理依赖和模型各有额外下载源 |
| 磁盘 | 基础网关先预留数 GiB（吉字节）；原生编译、视觉与记忆模型需更多空间 |
| 内存与处理器 | 安装器据当前可用资源限制编译并行数；资源不足可用 `--jobs 1`，运行性能另行测量 |
| GPU（图形处理器） | 基础网关不要求；本地视觉与模型推理需按模型选择配置 |

这些是安装器范围与开发建议，不是每一种系统和模块组合均通过实机认证。Windows（微软操作系统）与 macOS（苹果操作系统）可使用浏览器访问已部署网关，当前没有对应的原生一键安装承诺。容器或虚拟机还需自行处理传感器、网络和硬件访问。

Go2（宇树四足机器人）所需厂商软件包由设备环境或授权渠道提供。Jetson（嵌入式计算平台）上的视觉模块需要与 JetPack（厂商软件栈）匹配、可导入的张量与视觉库；普通电脑安装成功不能作为该设备的兼容证明。

## 准备终端和源码

在 Ubuntu/Debian 的终端里先确认：

```bash
python3 --version
git --version
```

缺少基础工具时，由具有管理员权限的用户安装：

```bash
sudo apt-get update
sudo apt-get install -y git python3 python3-venv
```

获取当前开发源码：

```bash
git clone --branch refactor/map-explore-nav https://github.com/Molun0301/nuwax-embodied-harness.git
cd nuwax-embodied-harness
```

仓库目前私有，需要所有者授予读取权限。HTTPS（加密网页传输协议）克隆需已配置的 GitHub（代码托管平台）凭据；也可以使用已配置的 SSH（安全远程连接）密钥克隆同一仓库。不要把访问令牌写进克隆地址、脚本或问题报告。

使用网页下载源码压缩包时，先切换到上述开发分支，再下载并解压。终端进入含 `install.sh`、`install.py` 和 `scripts/` 的根目录。压缩包不含版本管理记录，后续升级需要重新取得完整源码。

## 安装前检查

只接入状态、视频与接口，先选基础方案：

```bash
./install.sh doctor --preset basic --robot customrobot
```

诊断列出“通过”“提示”“需处理”。存在“需处理”时退出码为1；全部检查没有阻断项时为0。“尚未安装”及下载源未探测属于提示，不能解释成机器人已就绪。

查看包含二维或三维建图的完整方案：

```bash
./install.sh install --preset map2d --robot customrobot --dry-run
./install.sh install --preset map3d --robot customrobot --dry-run
```

`--dry-run`（只查看计划）不安装软件；`doctor`（环境检查）还会运行只读解释器、厂商依赖和已有产物检查。诊断不下载软件，也不验证传感器或网络下载速度。

## 需要预先知道的设备信息

不接运动也可以先完成基础软件体验。准备接入功能时，逐项收集：

- 机器人和传感器型号、固件版本、连接方式、厂商开发包来源。
- 数据单位、真实采集时间、时钟关系、每帧坐标系和传感器外参。
- 选用二维激光、三维激光惯性或设备已有里程计的哪条路径。
- 机体尺寸、允许速度与运动方式、独立停止方法、执行反馈。
- 地图、日志、模型和记忆数据库的存储位置。

接入步骤和契约源码见[架构与机器人接入](架构与机器人接入.md)。
