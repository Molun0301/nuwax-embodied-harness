# 快速上手

本指南带你安装 Nuwax Embodied Harness（NEH，具身运行框架）、打开控制台、完成第一次建图与导航，再把机器人能力交给智能体。先完成基础软件与标准输入，再按设备条件增加建图和运动能力。

## 0. 运行安装命令

在目标设备终端执行[安装说明中的命令](安装与更新.md#一条命令安装并打开网页)。它匿名下载管理程序、安装服务并打开管理页；无桌面的设备会打印网页地址，在电脑浏览器中打开即可。

## 1. 选择机器人与模块

在管理页查看系统、架构和解释器的检测结果，选择机器人和模块：

- 只看状态、视频和接口：选 `core`。
- 二维激光建图：加 `slam2d`；三维激光惯性建图：加 `fastlio2` 或 `pointlio`（可以都装）。
- 需要导航和探索：加 `navigation`；需要本地识别和记忆：加 `perception`、`memory`。

FastLIO2（快速激光惯性里程计）与 PointLIO（逐点激光惯性里程计）在设备本机从源码编译，其余程序优先使用云端预编译产物。安装完成后，从管理页进入业务控制台。

## 2. 配置并连接设备

在管理页或控制台“设置”中填写机器人、设备地址、传感器与标定，保存后按提示重启业务。命令行也可以查看和修改同一份配置：

```bash
neh config
neh config --set perception.stream_interval_sec 0.8
neh restart --wait
neh status
```

键名与生效方式见[配置说明](配置说明.md)，接入自己的设备见[架构与机器人接入](架构与机器人接入.md)。在控制台确认状态、相机画面和雷达/惯性数据已经到达。没有设备输入时显示等待或缺项是正常的；安装不会生成模拟数据，也不会替你完成标定。

## 3. 完成一次建图

建图会话的开始、保存、加载由能力接口提供（MCP 工具、智能体接口或 HTTP 调用），控制台用于观察和发起探索。下面用设备上自带的轻量客户端演示，`一楼` 换成你的地图名：

```bash
client=~/Nuwax-embodied-harness/current/source/clients/robot_client.py
python3 "$client" invoke start_mapping --arguments '{"map_name": "一楼"}'
```

1. 开始建图后，在控制台确认轨迹与实际移动一致、地图持续更新。
2. 遥控机器人走完场地，或在控制台“导航 → 自动探索”中让机器人自行探索（探索会在同一地图会话里进行，结束时默认保存地图）。
3. 保存地图，它返回一个任务，等待其结束：

   ```bash
   python3 "$client" invoke save_map --arguments '{"map_name": "一楼"}'
   python3 "$client" wait 任务标识 --timeout-sec 60
   ```

4. 以后再用这张地图时，调用 `load_map`：它先加载再自动重定位，任务成功后机器人即可导航。

同名的记忆库随地图自动创建和切换。保存地图后建图仍在继续；不再需要时调用 `end_map_session` 结束会话（未保存的内容会丢弃）。二维视图看平面轮廓，三维视图看高度与空间结构；三维链路下切换到二维视图不会改变导航算法。

## 4. 导航、探索与记忆

**导航：** 在控制台打开“导航 → 选点导航”，单击地图选目标（三维视图点在地面上），点“开始导航”。默认到达位置误差 0.15 米以内即算到达，不检查最终朝向；通过接口指定 `yaw_rad` 时才检查朝向。看任务的最终结果，不只看“已受理”。

**探索：** 在“导航 → 自动探索”中填写地图名称、最长运行时间，可选总路程、返航余量和结束后返回起点，点“开始探索”。需要中断并保留进度时点“暂停并保存”；以后从“已保存的探索”继续，恢复时会重新加载并定位。

**识别与记忆：** 在“摄像头与识别”中开启手动识别，查看检测结果；记忆库绑定当前地图。只有观察位置、缺少物体几何依据的记录会标为“仅观察”。语义地图需要另行启用并配置决策服务，属于实验能力。

能力条件与限制见[功能列表](功能列表.md)，控制台操作见[控制台使用指南](控制台使用指南.md)。

## 5. 连接应用或智能体

在设备上只读检查网关和能力目录：

```bash
curl -fsS http://127.0.0.1:8766/api/health
curl -fsS http://127.0.0.1:8766/api/agent/tools
python3 "$client" info
```

MCP（模型上下文协议）入口是 `http://127.0.0.1:8766/mcp`；从其它电脑连接见[智能体接入](智能体接入.md)。健康接口有响应只表示网关可用，建图、导航或识别是否可用要看各自的输入与任务结果。

## 没有机器人时验证基础流程

安装完成后，可以用当前版本的环境运行离线检查：

```bash
~/Nuwax-embodied-harness/current/venv/bin/python ~/Nuwax-embodied-harness/current/source/scripts/diagnostics/offline_platform_smoke.py
```

它在临时目录里建立独立配置，启动真实网关、真实运动守卫和一个同协议的模拟几何运行时，依次执行开始建图 → 保存 → 加载并重定位 → 导航 → 运动中急停，最后输出 JSON 结果。不连接机器人，不下载识别模型。它只说明软件接线正常，实机运动、识别与建图精度需要另外验证。安装在其它目录时，替换命令中的路径。
