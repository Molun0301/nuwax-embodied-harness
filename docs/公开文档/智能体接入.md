# 智能体与应用接入

Nuwax Embodied Harness（NEH，具身运行框架）向上层应用提供机器人能力：读取状态、拍照与识别、建图与地图管理、导航与探索、空间记忆检索与找目标。对话、模型选择和高层规划由你的应用负责。网页控制台、MCP 和 HTTP 接口调用的是同一组能力，结果和错误相同。

## 选择入口

| 入口 | 适合的调用方 | 地址（设备本机） |
| --- | --- | --- |
| MCP（模型上下文协议） | 支持该协议的智能体 | `http://127.0.0.1:8766/mcp` |
| 智能体 HTTP（超文本传输协议）接口 | 自建应用、脚本与轻量客户端 | `http://127.0.0.1:8766/api/agent` |
| 公共能力接口 | 前端或需要直接调用能力的程序 | `POST http://127.0.0.1:8766/api/capabilities/能力名/invoke` |
| 浏览器控制台 | 人工观察、操作和调试 | `http://127.0.0.1:8766/console` |

业务网关只监听设备本机。从其它电脑或容器连接时：

- **未设置管理页密码**：经管理页地址访问，例如 `http://设备地址:8765/mcp`、`http://设备地址:8765/api/agent`（管理页把这些路径转发给网关）。
- **已设置管理页密码**：转发路径需要浏览器登录会话，程序客户端改用 SSH（安全远程连接）隧道：`ssh -N -L 8766:127.0.0.1:8766 设备别名`，再连接本机 `http://127.0.0.1:8766`。
- **容器里**的 `127.0.0.1` 指容器自己，要填容器能访问到的设备地址。

下文示例在设备本机执行。

## 先发现能力

仓库自带的[轻量客户端](../../clients/robot_client.py)只依赖 Python（编程语言）标准库，可以单文件复制到应用环境；在已安装的设备上位于 `~/Nuwax-embodied-harness/current/source/clients/robot_client.py`。

```bash
python3 clients/robot_client.py --url http://127.0.0.1:8766 info
python3 clients/robot_client.py --url http://127.0.0.1:8766 tools
python3 clients/robot_client.py --url http://127.0.0.1:8766 tools --name navigate_to_pose
```

能力目录给出真实的工具名称、说明和参数结构，随机器人型号和配置变化。目录里有某个工具，只说明可以调用；调用时网关按需启动所需组件，组件或数据未就绪时返回具体原因。不需要硬编码一份工具全集。

## 使用 MCP

在智能体客户端中添加 HTTP 类型的 MCP 服务器，地址填 `http://127.0.0.1:8766/mcp`。客户端初始化后调用 `tools/list`（工具发现）：**每个能力就是一个工具**，`inputSchema` 就是它的参数结构。调用时 `tools/call`（工具调用）的 `name` 填能力名，`arguments` 直接填参数对象：

```json
{"name": "navigate_to_pose", "arguments": {"x": 1.5, "y": 0.8}}
```

业务错误作为工具结果返回，`isError` 为真，`structuredContent.error` 含 `code`、`message`、`details`；按 `code` 判断错误种类，不按中文消息判断。

## 调用与结果

```bash
python3 clients/robot_client.py invoke get_robot_status
python3 clients/robot_client.py invoke navigate_to_pose --arguments '{"x": 1.5, "y": 0.8}'
```

直接调用 HTTP 接口时，请求体为 `{"tool_name": "能力名", "arguments": {...}}`：

```bash
curl -fsS http://127.0.0.1:8766/api/agent/invoke -H 'Content-Type: application/json' \
  --data '{"tool_name":"get_robot_status","arguments":{}}'
```

能力分三类：**查询**立即返回数据；**动作**同步执行并返回结果；**任务**（导航、探索、保存与加载地图、找目标等）立即返回 `{"task": {...}}`，其中 `task_id` 是任务标识，之后跟踪这个任务。接口没有请求去重或自动重放：响应丢失时先查询任务和机器人状态，不盲目重发运动命令。

## 跟踪长任务

```bash
python3 clients/robot_client.py task TASK_ID
python3 clients/robot_client.py wait TASK_ID --timeout-sec 30
python3 clients/robot_client.py result --task-id TASK_ID
python3 clients/robot_client.py cancel TASK_ID
```

`TASK_ID` 换成实际返回值。任务状态：`running`（运行中）→ `succeeded`（成功）或 `failed`（失败）；取消或到期时先进入 `cancelling`（取消中），处理器退出后成为 `cancelled`（已取消）或 `timed_out`（已超时）。

- 一次 `wait` 结束不等于任务结束，按返回状态继续等待或查询。
- 取消只是发出取消；涉及运动时，运动守卫在执行方停止续租后 0.75 秒内把速度归零。
- 任何新的运动命令（导航、探索、相对移动等）直接替换正在进行的运动任务，旧任务以 `cancelled` 结束，不需要先取消。
- 关闭网页、退出客户端或等待超时都不会取消已受理的任务。
- 任务只保存在网关内存中（活动任务加最近 200 个终态），网关重启后清空，不会自动续跑。探索可以从已保存的检查点恢复。

需要实时进度时订阅功能反馈流：`python3 clients/robot_client.py watch --task-id TASK_ID`（对应 `GET /api/feedback/stream`）。MCP 客户端可通过 `GET /mcp` 接收 `notifications/message` 通知。反馈流断线后从最后收到的位置续传；收到 `feedback.gap`（反馈缺口）时重新查询任务状态，不重新执行动作。

## 让调用对应可验证的结果

一个“去门口看看”的任务，可以这样组织：

1. 查询机器人状态与当前地图（`get_robot_status`、`get_active_map`）。
2. 从当前地图的命名地点或记忆中解析“门口”（`query_location`、`resolve_navigation_candidates`）。
3. 发起导航（`navigate_to_pose` 或 `navigate_to_named_location`），保存任务标识并等待最终结果。
4. 到达后拍照或识别（`capture_image`、`perceive_current_scene`）。
5. 分别报告是否到达、现场看到了什么，并引用实际图像。

检索到物品、区域相邻、得到导航候选，都不等于路线已可执行；地图不匹配、只有观察位置或证据过期时，保留返回的具体原因。

## 读取语义地图

启用语义地图后，以下工具提供区域与空间关系（实验能力）：

| 工具 | 返回内容 |
| --- | --- |
| `get_semantic_map` | 区域边界、名称、候选与版本 |
| `get_scene_graph` | 区域、连接口、物品和观察节点及邻接关系 |
| `get_scene_graph_node` | 节点位置、范围与图像引用 |
| `plan_scene_graph_route` | 区域之间的候选连接链，不执行运动 |
| `render_scene_graph_image` | 带编号的地图图像与编号对照 |
| `locate_current_scene_space` | 机器人当前所在区域 |
| `update_scene_space_label` | 按预期修订修改区域名称 |

修改名称时带上当前区域标识和修订，冲突时重新读取。模型只给区域用途候选，不生成导航坐标。

## 图像与其他文件

拍照或地图图像工具返回制品引用。用返回的 `artifact_id`（制品标识）下载后再交给支持图像输入的模型：

```bash
python3 clients/robot_client.py artifact ARTIFACT_ID --output ./现场图像.jpg
```

能力结果本身不包含栅格、点云或图像字节，只给引用。工具中的文字摘要不等于模型已经看过原始图像。完整提示词见[机器人智能体提示词](机器人智能体提示词.md)，任务示例见 [Go2 提示词示例](Go2提示词示例.md)。

## 外部设备操作

`execute_manipulation_task`（外部设备操作）把自然语言操作指令交给配置的外部设备并跟踪其物理结果，默认关闭。启用需在配置中设置 `manipulation.enabled` 与 `manipulation.base_url`（外部设备的 HTTP 地址）。任务受理不代表成功；取消会转发给设备，不等待停稳证明。
