# 预编译许可证清单

本清单只覆盖 focal-arm64（Ubuntu 20.04 ARM64）与 noble-x86_64（Ubuntu 24.04 x86_64）的五个可预编译程序。当前正在生成实际编译、链接及许可记录，尚未批准这些记录对应的发布。机器可校验结论保存在 [逐程序审核记录](../../third_party/prebuilt-license-review.json)；任一程序或平台未批准时，完整提交索引拒绝发布。

| 程序 | 核查范围 | 当前结论 |
| --- | --- | --- |
| nuwax-slam-2d-worker | Rust（编程语言）实际依赖、Karto/slam_toolbox 动态核心、思岚驱动及私有依赖 | 等待本轮实际记录 |
| nuwax-geometry-runtime | Rust 实际依赖、原生规划、点过滤与几何优化组件 | 等待本轮实际记录 |
| nuwax-nav-stack | Rust 实际依赖与所启用原生规划组件 | 等待本轮实际记录 |
| nuwax-person-follow | Rust 实际依赖与 LCM（轻量通信与编组）运行库 | 等待本轮实际记录 |
| nuwax-mapping-cli | Rust 实际依赖与实际链接的几何优化组件 | 等待本轮实际记录 |

核查依据为编译器生成的依赖记录、真实最终链接参数及其解析出的对象或库、锁定的外部来源、实际读取或链接组件的版权与许可正文。附件附带这些记录、许可证以及适用的对应源码和替换/重建材料；不以整个缓存目录推断程序组成。许可核查标识绑定输入路径、组件身份、链接来源及许可正文，变化后须重新核对。程序内容仍由独立的程序指纹约束。

二维核心中的 `nanoflann_adaptors.h` 保留上游不完整 CCPL（知识共享公共许可证）前言，未指明具体类型或版本。[作者在该头加入后的2021年论文](https://www.theoj.org/joss-papers/joss.02783/10.21105.joss.02783.pdf)明确声明整个 slam_toolbox 软件包采用 LGPLv2.1（宽通用公共许可证第2.1版）；[固定版本 Karto 包声明](https://github.com/SteveMacenski/slam_toolbox/blob/6953058b8994c7e750277fd8f39b984453abf63c/lib/karto_sdk/package.xml#L9)为 LGPLv3。此处保留整体许可依据和文件头差异，不把前言补写成某一具体 CC 许可证，也不据此断言已经确认新的不兼容。实际文件上的明确许可与原版权仍需完整保留。

`fastlio2_native` 与 `pointlio_native` 始终由设备从固定源码本机增量编译，不属于本清单，不在任何 Release（发布集合）分发二进制或额外LIO（激光惯性里程计）源码包。其包装与算法许可组合，以及设备出货前的授权要求，见[第三方许可证说明](第三方许可证说明.md)。
