# 配置说明

Nuwax Embodied Harness（NEH，具身运行框架）将安装选择与机器人配置分开管理：安装器负责软件及程序位置，控制台负责设备和功能参数。

## 找到正在使用的配置

正式安装在设备管理页查看和编辑配置，也可运行：

```bash
~/Nuwax-embodied-harness/bin/neh config
~/Nuwax-embodied-harness/bin/neh config --set NUWAX_LOG_LEVEL INFO
```

新安装的默认持久配置位于`~/Nuwax-embodied-harness/config/profiles/<机器人>/<方案>.env`，`data/settings/active.env`选择当前方案。业务版本的源码目录会接到这些持久文件，升级不能覆盖为初始默认值。已有旧安装仍使用原位置；在网页另选业务目录时，配置保存在该目录中。网页与命令行共用配置快照，保存时拒绝过期编辑；读取返回的敏感字段经过遮盖。

既有源码模块安装仍通过`./install.sh list`查询实际位置，其初始配置为`runtime_data/installation/current/settings.env`，保存后的具名方案位于`drivers/<机器人>/configs/<方案>.env`。请按实际安装入口查询，避免编辑其它版本的初始文件。

控制台“设置”区分当前编辑、已选择、进程启动时的方案。**浏览方案、保存方案、应用方案、重启生效是不同动作。**先核对机器人与方案，再保存、应用，并按页面提示完成重启。

## 第一次本机体验

全新模块安装默认监听 `127.0.0.1`（本机地址），端口默认8766。没有既有配置时，初始文件中的关键值为：

```dotenv
NUWAX_ACTIVE_ROBOT=customrobot
NUWAX_GATEWAY_HOST=127.0.0.1
NUWAX_GATEWAY_PORT=8766
NUWAX_GATEWAY_PUBLIC_BASE_URL=http://127.0.0.1:8766
```

`customrobot` 是标准接入入口，不会自动探测厂商设备。已有明确配置会被沿用；从旧 `.env` 迁入的地址可能仍是 `0.0.0.0`（所有网络接口），请核对实际值。

`NUWAX_GATEWAY_PUBLIC_BASE_URL` 是调用者下载图像等制品时使用的地址，应该从调用者所在机器或容器可达。它不会改变服务监听位置。远程访问方法见[安全与数据说明](安全与数据说明.md)。

## 先决定安装模块，再设置设备

| 配置内容 | 如何处理 |
| --- | --- |
| 二维或三维链路 | 使用模块安装器选择 `slam2d`、`fastlio2` 或 `pointlio`；`NUWAX_GEOMETRY_PIPELINE` 与选择保持一致 |
| 原生程序和解释器路径 | 由安装器写入；增删或修复模块使用安装器 |
| 传感器与标定 | 按真实设备填写、在接入装配中提供；不能复制别的机器人的外参 |
| 运动执行器 | 绑定真实速度/停止接口，按运动守卫工厂配置接入 |
| 机器人外形 | 使用实际模型或实测尺寸，三维导航还需机体到支撑面的距离 |
| 视觉和本地记忆 | 先安装相应模块，再选择模型路径、后端与参数 |
| 语义地图决策 | 独立配置决策后端和服务；安装 `memory` 不等于该模型已部署 |

公共键全集以[配置示例](../../.env.example)与运行中“设置”页为准；Go2 设备参数另见[设备示例](../../drivers/go2/data_plane.env.example)。代码内部 `NUWAX_*` 前缀继续使用，不能直接替换为 `NEH_*`。

## 文件格式

每行一个 `KEY=value`，可使用注释和引号，同名键最后一行生效。路径建议使用实际绝对路径；解析器不运行命令，也不展开 `$HOME` 或 `$(...)`。

```dotenv
# 示例：请替换成自己机器上的真实路径
NUWAX_LOG_DIR=/srv/neh-data/logs
```

显式进程环境优先于文件配置。终端或系统服务导出过同名变量时，网页保存文件后可能仍被环境值覆盖。根据设置页的“来源”“保存位置”“进程读取值”定位问题。

## 精细点云缓存预算

“设置 → 几何引擎·点云与质量 → 精细点云缓存模式与预算”可选择自动或固定，单位 MiB（二进制兆字节）。

- 自动：从 32 MiB 开始，缓存即将因超预算整体写出时先尝试扩容。自动上限可填 32～4096 的整数，默认 256；达到上限后按固定预算处理并记录一次警告。
- 固定：预算可填 16～4096 的整数，此时忽略自动上限。较大预算可减少反复编码和解码，但会使用更多内存。

在线建图与 PGO（位姿图优化）私有重放的写入器分别使用预算与上限；两者同时存在时，此值不是合计内存上限。两种模式的地图输出相同，只影响速度和内存。二维执行链下页面禁用这两项。

配置文件示例：

```dotenv
NUWAX_GEOMETRY_FINE_CLOUD_CACHE_MIB=auto
NUWAX_GEOMETRY_FINE_CLOUD_CACHE_AUTO_MAX_MIB=256
```

固定 64 MiB 时将第一项改为 `64`。未设置或留空分别使用 `auto` 与 `256`；其它非法值在保存时拒绝。保存后须重启几何运行时；设置页展示文件值和待重启状态，不代表已确认外部进程实际采用。

## 保存后怎样确认

“设置 → 导航与探索 → 启用局部规划”对应 `NUWAX_NAV_LOCAL_PLANNING_ENABLED`，仅用于三维导航；二维链路不使用此项，页面中会禁用。默认开启，缺省或空值也使用开启。`true/1/yes/on` 表示开启，`false/0/no/off` 表示关闭，忽略两端空白和大小写；其它值拒绝保存。保存后需重启导航后端，设置页不会将文件值或网关启动配置标为后端已实际采用。

关闭局部规划后沿全局路径执行，地图与输入新鲜度检查、运动守卫和停车条件仍然有效。不要把关闭此项作为绕过执行安全检查的方法。重启后还应核对导航后端的启动日志与任务状态。

1. 确认编辑的是目标机器人方案。
2. 保存，核对成功、拒绝和跳过的字段；修改失败时保留具体原因。
3. 应用目标方案；涉及设备、通信和算法初始化的项按提示重启。
4. 重连后确认进程实际读取值，再确认数据和功能是否就绪。

网页显示“外部进程读取值未知”时，不能以文件中已有该值判断算法已采用它。更改网关地址或端口后，应使用新地址访问。正式产品通过管理页或`~/Nuwax-embodied-harness/bin/neh restart --wait`按原拥有方重启。源码模块安装的普通启动仍使用`./install.sh start`。

## 原始扫描暂存

完成地图清理需要原始扫描及校正后的最终位姿。可在配置页“几何引擎·点云与质量”展开高级项，或在当前方案文件设置：

| 键 | 默认与范围 | 生效 |
| --- | --- | --- |
| `NUWAX_RAW_SCAN_DIRECTORY` | 空值使用运行数据根下的`scan_logs`；相对路径按项目工作目录解析 | 重启网关与几何运行时 |
| `NUWAX_RAW_SCAN_MAX_MIB` | 8192 MiB（兆二进制字节）；64～1048576的十进制整数 | 重启几何运行时 |

暂存达到预算或写入失败时，该会话停止辅助扫描记录，建图和地图保存继续；清理结果明确历史不完整。未固化的扫描不会为腾空间自动删除。成功发布地图且已有完整副本后，原写入器关闭、无新增记录的暂存可由后续会话回收；地图资产内的副本独立保留。离线清理沿用上文精细点云写入器缓存设置。
