# 项目功能与实现情况清单

核对日期：2026年11月8日，代码基线 `22306766`。本文按模块列出 Nuwax Embodied Harness（NEH，具身运行框架）的功能，区分代码实现、使用条件与验证情况。依据为当前源码、能力定义、配置模式与已有验证记录；历史验证只代表对应日期、版本与场景。

## 一、状态口径与当前结论

| 实现状态 | 含义 | 不代表什么 |
| --- | --- | --- |
| 已实现 | 有实际处理逻辑，已接入调用链 | 不代表默认开启、所有设备可用或没有缺陷 |
| 已接通，待完善 | 主要流程存在，关键效果、稳定性或配套能力仍有明确缺口 | 不作为完整功能验收通过 |
| 实验性实现 | 已有代码或本地闭环，用于验证方案，适用范围有限 | 不作为成熟能力承诺 |
| 待实现 | 只有入口或占位，缺少实际执行后端 | 不能因为名称存在就判断可用 |

当前结论：

- **2026年11月完成全项目结构重构**：业务进程由统一监督者启停、几何运行时以会话为中心、配置统一为模式文件加方案、所有运动经运动守卫。重构后的完整链已在隔离的真实组件闭环与仿真平台上验证。
- **仿真平台（`unitree_sim`，Go2 型号，办公室场景，2026-11-08）**：实时建图中两次选点导航到达，真值误差约 3 厘米与 13 厘米；找目标找到盆栽候选、前往物体外的观察位置并复核通过；运动中急停后速度归零、旧命令被拒。有边界探索按时长结束但没有完成子目标（两个子目标规划失败）。
- **Go2 实机**：当前版本尚未完成统一复验；旧版本地图格式不迁移，需要重新建图。
- **语义区域与关系图**：几何、证据、标签与存储链已接通，现场自动识别房间用途仍是实验能力。

## 四、按实现情况汇总

**已实现的基础能力**：设备接入（Go2、仿真设备、通用接入、二维雷达）、运动守卫、二维/三维建图与回环、地图会话与资产、禁行区、空间记忆与找目标、能力与任务接口、控制台与配置、安装更新。

**已接通但尚未完整交付**：复杂三维场景导航、区域探索的子目标成功率与真实覆盖、楼宇跨层实机、人物跟随的目标连续性、分割模型、网关访问认证。

**实验性能力**：语义区域用途识别与关系图路线。

**待实现**：G1 与树莓派雷达机器人整机适配；语音识别与对话不在当前范围。

## 五、阅读边界

本清单描述代码现状与已有验证，不是验收报告。仿真平台的结果使用仿真传感器与物理，实机上的定位精度、识别准确率、运动表现需要在目标设备上重新验证。设备投入使用前的验收步骤见[发布与兼容性](发布与兼容性.md)。
