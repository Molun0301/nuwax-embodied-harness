# 历史验证证据

本目录保存从 `docs/` 顶层迁入的 184 份历史调查、方案、试验与结果文件。原有文件名和 JSON（结构化数据格式）、JSONL（逐行结构化数据）、文本结果保留；文档相对链接按新位置调整。

这些记录只对应各自的日期、版本、输入和验收范围。文件中的历史命令、当时的工作区状态、旧路径和固定提交链接属于原始证据，不代表当前推荐入口或当前能力承诺。

当前使用说明见[公开文档导航](../公开文档/阅读指南.md)，软件维护见[安装与更新](../公开文档/安装与更新.md)。其它已整理的诊断材料保留在 [diagnostics（诊断）目录](../diagnostics/)。
