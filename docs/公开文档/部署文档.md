## 1. 环境要求

### 硬件

| 项目 | 最低要求 | 推荐 |
|------|----------|------|
| 平台 | ARM64 或 x86_64 Linux | Jetson Orin / Go2 内置主机 |
| 内存 | 4 GB | 8 GB+ |
| 存储 | 10 GB 可用空间 | 20 GB+（含模型权重） |
| GPU | 无（CPU 可运行） | CUDA GPU（感知加速） |

### 软件

| 依赖 | 版本 | 用途 |
|------|------|------|
| Python | 3.10+ | 网关运行时 |
| ROS 2 | Jazzy（推荐）/ Humble / Iron | RTAB-Map + Nav2 几何栈 |
| Docker | 20.10+（可选） | NuwaxClaw 容器客户端 |

### 网络

- Go2 机器人与宿主机在同一局域网（DDS 通信）
- 宿主机端口 `8766`（网关）、`6080/60005/60006`（NuwaxClaw 容器，可选）

## 2. 快速部署（一键）

适合首次部署或重新部署。`bootstrap.py` 会自动完成环境检查、依赖安装、配置生成和工作区构建。

### 2.1 克隆仓库

```bash
git clone <your-repo-url> ~/nuwax-robot-bridge
cd ~/nuwax-robot-bridge
```

### 2.2 环境检查

```bash
python3 scripts/bootstrap.py check \
  --robot go2 \
  --tier full \
  --geometry \
  --data-plane \
  --memory-mode cloud \
  --perception-mode hybrid \
  --mcp-mode auto
```

检查通过后会输出 `All checks passed`。如有失败项，按提示修复后重新检查。

### 2.3 执行部署

**交互式（推荐首次使用）：**

```bash
python3 scripts/bootstrap.py wizard
```

向导会依次询问：机器人类型 → 部署档位 → geometry/data-plane/memory/perception → MCP 模式 → 是否安装 NuwaxClaw Docker 客户端。

**无交互式（适合自动化）：**

```bash
python3 scripts/bootstrap.py apply --non-interactive \
  --robot go2 \
  --tier full \
  --geometry \
  --data-plane \
  --memory-mode cloud \
  --perception-mode hybrid \
  --systemd \
  --mcp-mode auto
```

部署完成后会生成：

| 生成物 | 路径 |
|--------|------|
| 根配置 | `.env` |
| Go2 数据面配置 | `drivers/go2/data_plane.env` |
| Python 虚拟环境 | `.venv/` |
| systemd 服务文件 | `deploy/systemd/nuwax-host-gateway.service` |
| MCP 配置 | `deploy/nuwaclaw/external_mcp_servers.host_gateway.json` |

### 2.4 启动网关

```bash
bash scripts/start_gateway.sh
```

### 2.5 验证

```bash
curl http://127.0.0.1:8766/api/health \
  -H 'Authorization: Bearer agent-robot-bridge-token'
```

返回 `200` 即部署成功。

## 3. 手动部署（分步）

适合需要精细控制每个环节的场景，或一键部署遇到问题时逐步排查。

### 3.1 安装 Python 依赖

```bash
cd ~/nuwax-robot-bridge
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 3.2 安装 ROS 2 与 RTAB-Map/Nav2

确认 ROS 2 环境可用：

```bash
source /opt/ros/jazzy/setup.bash   # 或 humble/iron
echo "$ROS_DISTRO"
```

安装几何栈依赖：

```bash
sudo apt-get update
sudo apt-get install -y \
  build-essential cmake \
  python3-colcon-common-extensions \
  python3-rosdep python3-vcstool \
  ros-$ROS_DISTRO-rtabmap-ros \
  ros-$ROS_DISTRO-navigation2 \
  ros-$ROS_DISTRO-nav2-bringup \
  ros-$ROS_DISTRO-robot-localization \
  ros-$ROS_DISTRO-pointcloud-to-laserscan \
  ros-$ROS_DISTRO-tf-transformations \
  ros-$ROS_DISTRO-rmw-cyclonedds-cpp
```

### 3.3 构建 ROS 2 工作区

```bash
sudo rosdep init || true
rosdep update
cd services/geometry/ros2_ws
rosdep install --from-paths src --ignore-src -r -y
cd ~/nuwax-robot-bridge
bash services/geometry/build_ros2_workspace.sh
```

Go2 还需构建嵌套工作区：

```bash
cd services/geometry/ros2_ws/src/go2slam
rosdep install --from-paths src --ignore-src -r -y
colcon build --symlink-install
cd ~/nuwax-robot-bridge
```

验证构建结果：

```bash
bash services/geometry/launch_ros2_stack.sh ros2 pkg prefix rtabmap_ros
bash services/geometry/launch_ros2_stack.sh ros2 pkg prefix nav2_bringup
bash services/geometry/launch_ros2_stack.sh ros2 pkg prefix go2_navigation2
```

### 3.4 配置 `.env`

复制模板并编辑：

```bash
cp .env.example .env
```

Go2 全量部署的关键配置项：

```dotenv
NUWAX_ACTIVE_ROBOT=go2
NUWAX_PYTHON_BIN=.venv/bin/python3
NUWAX_ROS_SETUP_SCRIPT=/opt/ros/jazzy/setup.bash
NUWAX_GEOMETRY_ENABLED=true
NUWAX_GEOMETRY_STACK=external_slam_nav2
NUWAX_GEOMETRY_SETUP_SCRIPT=services/geometry/ros2_ws/install/setup.bash
NUWAX_GEOMETRY_EXTERNAL_SCRIPT=services/geometry/start_rtabmap_sidecar.sh
NUWAX_GEOMETRY_ODOM_TOPIC=/odom
NUWAX_GEOMETRY_POINT_CLOUD_TOPIC=/utlidar/cloud
NUWAX_GEOMETRY_IMU_TOPIC=/utlidar/imu
NUWAX_GEOMETRY_OCCUPANCY_TOPIC=/map
NUWAX_GEOMETRY_MAP_FRAME=map
NUWAX_GEOMETRY_ODOM_FRAME=odom
NUWAX_GEOMETRY_BASE_FRAME=body
NUWAX_GEOMETRY_LIDAR_FRAME=utlidar_lidar
NUWAX_NAV2_MODE=sidecar
NUWAX_GATEWAY_AGENT_TOKENS=agent-robot-bridge-token
NUWAX_GATEWAY_ADMIN_TOKENS=admin-robot-bridge-token
```

### 3.5 启动网关

```bash
bash scripts/start_gateway.sh
```

网关启动后会自动：
1. 加载 `.env` 配置
2. 启动 RTAB-Map + Nav2 侧车进程（如果 `NUWAX_GEOMETRY_ENABLED=true`）
3. 启动 Go2 视频推流（如果配置了数据面）
4. 在 `0.0.0.0:8766` 监听 HTTP/WebSocket 请求

### 3.6 配置 systemd（可选）

```bash
sudo cp deploy/systemd/nuwax-host-gateway.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now nuwax-host-gateway
```

查看状态和日志：

```bash
sudo systemctl status nuwax-host-gateway
journalctl -u nuwax-host-gateway -f
```

## 4. 部署后验证

### 4.1 网关健康检查

```bash
curl http://127.0.0.1:8766/api/health \
  -H 'Authorization: Bearer agent-robot-bridge-token'
```

### 4.2 能力列表

```bash
curl http://127.0.0.1:8766/api/tools \
  -H 'Authorization: Bearer agent-robot-bridge-token'
```

### 4.3 几何栈验证（启用 geometry 时）

确认 ROS 2 话题和 action 已就绪：

```bash
bash services/geometry/launch_ros2_stack.sh ros2 topic list | grep -E "map|odom|cloud"
bash services/geometry/launch_ros2_stack.sh ros2 action list | grep navigate_to_pose
```

预期输出包含：`/map`、`/odom`、`/utlidar/cloud`、`/navigate_to_pose`。

### 4.4 Web 调试面板

浏览器打开：

```text
http://127.0.0.1:8766/debug
```

通过 SSH 隧道远程访问：

```bash
ssh -L 8766:127.0.0.1:8766 unitree@<Go2_IP>
# 然后本地浏览器打开 http://127.0.0.1:8766/debug
```

### 4.5 容器侧联通验证（安装了 NuwaxClaw 时）

```bash
docker exec -it nuwax-client sh -lc \
  "curl http://host.docker.internal:8766/api/health \
   -H 'Authorization: Bearer agent-robot-bridge-token'"
```

## 5. 可选组件

### 5.1 NuwaxClaw Docker 客户端

NuwaxClaw 是上层智能体容器，通过宿主机网关获取机器人能力。

**一键安装：**

```bash
python3 scripts/bootstrap.py apply --non-interactive \
  --robot go2 --tier full --geometry --data-plane \
  --memory-mode cloud --perception-mode hybrid \
  --mcp-mode auto \
  --install-nuwaclaw-docker \
  --nuwaclaw-host-mount ro \
  --nuwaclaw-saved-key <你的个人密钥>
```

**手动安装：**

```bash
docker run -d \
  --name nuwax-client \
  --restart always \
  --add-host=host.docker.internal:host-gateway \
  -p 6080:6080 -p 60005:60005 -p 60006:60006 \
  -v nuwax_home:/home/user \
  -v /:/host:ro \
  -e TZ=Asia/Shanghai \
  -e NUWAX_SERVER_HOST=https://agent.nuwax.com \
  -e NUWAX_AGENT_PORT=60006 \
  -e NUWAX_FILE_SERVER_PORT=60005 \
  -e NUWAX_WORKSPACE_DIR=/home/user/nuwaxbot/workspace \
  -e NUWAX_SAVED_KEY=<你的个人密钥> \
  nuwax-docker-images-registry.cn-hangzhou.cr.aliyuncs.com/nuwax/nuwax-agent-client:latest
```

宿主机挂载模式：`none`（不挂载）、`ro`（只读，推荐）、`rw`（读写，有安全风险）。

### 5.2 YOLO-World 感知模型

平台使用 YOLO-World + ByteTrack 实现开放词汇视觉感知。

**准备权重与 TensorRT engine：**

```bash
pip install -r requirements.txt
python3 scripts/prepare_yolo_world_tensorrt.py --device 0 --imgsz 640
```

**`.env` 配置：**

```dotenv
NUWAX_PERCEPTION_DEFAULT_DETECTOR_BACKEND=yolo_world
NUWAX_PERCEPTION_YOLO_WORLD_ENABLED=true
NUWAX_PERCEPTION_YOLO_WORLD_MODEL=runtime_data/models/yolov8s-worldv2.pt
NUWAX_PERCEPTION_YOLO_WORLD_DEVICE=0
NUWAX_PERCEPTION_TRACKER_BACKEND=bytetrack
```

Jetson 部署推荐导出 TensorRT FP16 engine 以获得实时性能。详见 `scripts/prepare_yolo_world_tensorrt.py --help`。

### 5.3 空间记忆模型

```bash
python3 scripts/prepare_memory_models.py
```

配置 `.env`：

```dotenv
NUWAX_MEMORY_MODE=cloud
NUWAX_MEMORY_ONLINE_MODEL=tongyi-embedding-vision-flash-2026-03-06
```

本地模式需额外安装 `requirements-memory-models.txt` 并下载嵌入模型。

### 5.4 MCP 注入模式

| 模式 | 行为 |
|------|------|
| `auto` | 生成配置 + 尝试安装外部 MCP hook |
| `config-only` | 只生成配置文件，不修改目标环境 |
| `skip` | 跳过 MCP 配置 |

推荐默认使用 `--mcp-mode auto`。

## 6. 常见问题与排障

### Q1: `/api/health` 返回 401 Unauthorized

**原因**：Token 不匹配。

**解决**：检查 `.env` 中的 `NUWAX_GATEWAY_AGENT_TOKENS`，确保请求 Header 中的 Bearer Token 与之一致。

### Q2: `/api/health` 返回 403 Forbidden

**原因**：请求来源 IP 不在白名单。

**解决**：检查 `.env` 中的 `NUWAX_GATEWAY_ALLOWED_SOURCE_CIDRS`，确保 Docker bridge 网段（通常 `172.17.0.0/16`）在白名单内。

### Q3: 网关启动后没有地图或导航状态

**排查步骤**：

1. 确认 RTAB-Map/Nav2 侧车进程在运行：
   ```bash
   ps aux | grep -E "rtabmap|nav2"
   ```

2. 检查侧车日志：
   ```bash
   cat runtime_data/geometry/logs/rtabmap_live.log
   cat runtime_data/geometry/logs/nav2.log
   ```

3. 确认 ROS 2 话题存在：
   ```bash
   bash services/geometry/launch_ros2_stack.sh ros2 topic list
   ```

4. 确认 TF 树完整：
   ```bash
   bash services/geometry/launch_ros2_stack.sh ros2 run tf2_ros tf2_echo map body
   ```

5. 检查 `.env` 中 topic/frame 配置是否与实际一致。

### Q4: ROS 2 包安装失败（apt 404 错误）

**现象**：`apt-get install ros-$ROS_DISTRO-rtabmap-ros` 报 404。

**原因**：ROS 2 apt 镜像索引与实际归档不同步。

**解决**：

```bash
# 方法1：bootstrap 自动修复（推荐）
python3 scripts/bootstrap.py apply --geometry ...
# bootstrap 会自动备份异常源并切换到备用镜像

# 方法2：手动切换源
sudo sed -i 's|mirrors.tuna.tsinghua.edu.cn/ros2|mirrors.ustc.edu.cn/ros2|g' \
  /etc/apt/sources.list.d/ros2*.list
sudo apt-get update
```

也可通过环境变量指定备用源：

```bash
export NUWAX_ROS2_APT_FALLBACK_URLS=https://mirrors.ustc.edu.cn/ros2/ubuntu
```

### Q5: RTAB-Map 启动报 TF_SELF_TRANSFORM 错误

**原因**：`map_frame_id` 和 `odom_frame_id` 配置为相同值。

**解决**：确保 `.env` 中 `NUWAX_GEOMETRY_MAP_FRAME` 和 `NUWAX_GEOMETRY_ODOM_FRAME` 不同（通常分别为 `map` 和 `odom`）。

### Q6: Go2SLAM 工作区构建失败

**排查步骤**：

1. 确认 Unitree ROS 2 接口包存在：
   ```bash
   ls services/geometry/ros2_ws/src/go2slam/src/unitree_go
   ls services/geometry/ros2_ws/src/go2slam/src/unitree_api
   ```

2. 确认 ROS 2 发行版一致：
   ```bash
   echo $ROS_DISTRO
   ```

3. 重新构建：
   ```bash
   cd services/geometry/ros2_ws/src/go2slam
   rm -rf build install log
   colcon build --symlink-install
   ```

### Q7: 外部 SLAM/Nav2 进程启动后立即退出

**排查步骤**：

1. 查看退出日志：
   ```bash
   cat runtime_data/geometry/logs/rtabmap_live.log
   cat runtime_data/geometry/logs/odom_tf_bridge.log
   ```

2. 常见原因：
   - `NUWAX_ROS_SETUP_SCRIPT` 路径错误
   - geometry 工作区未构建或与当前 ROS 发行版不匹配
   - `CYCLONEDDS_URI` 未正确设置
   - 传感器话题（`/utlidar/cloud`、`/odom`）无数据

3. 手动验证侧车脚本：
   ```bash
   bash services/geometry/launch_ros2_stack.sh \
     services/geometry/start_rtabmap_sidecar.sh
   ```

### Q8: NuwaxClaw 容器无法连接宿主机网关

**排查步骤**：

1. 确认容器启动时带有 `--add-host=host.docker.internal:host-gateway`
2. 在容器内测试连通性：
   ```bash
   docker exec -it nuwax-client ping host.docker.internal
   ```
3. 确认宿主机防火墙未阻止 8766 端口

### Q9: 感知链路报 `model_not_loaded_or_prediction_failed`

**解决**：
- 检查 `NUWAX_PERCEPTION_YOLO_WORLD_MODEL` 路径是否存在
- 确认 GPU 设备号正确（`NUWAX_PERCEPTION_YOLO_WORLD_DEVICE`）
- 确认 `requirements.txt` 已安装（含 ultralytics 依赖）
- Jetson 上确认 TensorRT engine 与当前 GPU/TensorRT 版本匹配

### Q10: 从 go2_inner_slam 分支切回 main 后异常

**解决**：必须重新构建 ROS 2 工作区，不能复用旧分支的 `install/setup.bash`：

```bash
cd services/geometry/ros2_ws
rm -rf build install log
cd src/go2slam && rm -rf build install log && cd ../..
bash ../build_ros2_workspace.sh
cd src/go2slam && colcon build --symlink-install
```
