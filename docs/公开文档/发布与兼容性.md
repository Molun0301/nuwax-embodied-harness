# 发布与兼容性

Nuwax Embodied Harness（NEH，具身运行框架）从固定源码提交在设备增量构建。本文更新于2026年10月15日，软件安装验证与机器人现场功能验收分别记录。

## 获取哪个版本

首次执行[单命令安装入口](轻量安装与自动发布.md#一条命令安装并打开网页)，随后在管理页选择模块。默认跟随`main`（主分支），任务固定完整提交，显示`git-提交前12位`。公开源码支持匿名下载。维护者推送代码后，设备直接检查更新并构建，无需选择云端附件。

## 当前软件交付与验证范围

| 范围 | 当前范围与条件 |
| --- | --- |
| 安装环境 | Linux x86_64及ARM64，Python 3.8—3.12；Ubuntu24开发机完成真实源码安装，Go2 Ubuntu20仍需对应系统及厂商环境 |
| 建图模块 | 二维、FastLIO2、PointLIO可以共同安装；两个 LIO 始终在设备本机从源码编译，产物不随本项目分发，出货预装前需兼容授权；当前运行链路与定位后端由配置选择 |
| 源码更新 | 固定提交、稳定Git和构建缓存、独立运行版本、失败保留旧版本；同提交且模块配置无变化时跳过构建与重启 |
| 本机实际增量证据 | x86_64上PointLIO首次50.59秒，无变化0.36秒，单个main.cpp修改16.91秒；只重编该对象并链接程序，其余71个对象和Livox库不变 |
| 基础网关 | 真实依赖安装、健康接口、更新复用Python环境、准备失败后旧网关继续运行已验证 |
| 网页与命令行 | 同一管理引擎提供安装、配置、启停、更新、回退、迁入和管理自更新；业务停止时管理页仍可用 |
| Go2官方依赖 | 固定宇树软件开发包和官方DDS（数据分发中间件）库来源，首次生成Python接口适配缓存；不代表本轮完成实机通信或运动验收 |
| 视觉、跟随与语义记忆 | 按所选模块准备推理依赖和模型；Jetson（嵌入式计算平台）厂商推理库需匹配；本轮未完成全模型推理验收 |
| 二维和三维运行 | 可以共同安装不等于同时运行；现场传感器、标定、定位精度、运动与复杂地图开销需按实际设备验证 |
| 访问与密码 | 管理页默认免密码，可设置密码；网页写入检查同源及会话 |
| 许可证 | 项目自有代码为 GPL-2.0-or-later（GNU 通用公共许可证第 2 版或更高版本）；第三方组件保留各自许可，见[第三方许可证说明](第三方许可证说明.md) |

历史`v0.1.0`预编译发布仍保留，新的日常安装与更新使用端侧源码流程。既有源码开发入口及历史部署的用途见[部署文档](部署文档.md)。

## 名称兼容

以下内部名称继续使用，不能做全仓库字符串替换：

| 保留内容 | 示例与原因 |
| --- | --- |
| Python/Rust（编程语言）包和程序 | `nuwax-*`、`nuwax_robot_bridge`；避免改变导入和构建 |
| 环境变量 | `NUWAX_*`、设备专用键；已有配置继续可读 |
| 协议与工具身份 | 消息通道、响应字段和协议服务器名称；避免破坏客户端 |
| 系统服务与数据目录 | `nuwax-host-gateway`、`/var/lib/nuwax_robot_bridge/`；避免影响运行部署 |
| 已有源码目录 | `/home/unitree/nuwax-robot-bridge` 等实际路径；仓库改名不会移动设备文件 |

旧克隆可在仓库根更新自己的远端地址：

```bash
git remote set-url origin https://github.com/Molun0301/nuwax-embodied-harness.git
```

设备路径与系统服务不随该命令改名。合作方和自动化配置中的仓库链接也需核对。

## 设备投入使用前的验收

安装成功说明文件、依赖和软件入口完成准备；现场还需核对实际传感器输入、定位和地图、运动执行、停止与异常恢复。视觉与模型组合必须使用与设备软件栈匹配且完成加载验证的依赖。长期运行还需观察磁盘增长、断线恢复及场景计算开销。

详细能力见[功能列表](功能列表.md)，正式安装与回退见[轻量安装与自动发布](轻量安装与自动发布.md)。
