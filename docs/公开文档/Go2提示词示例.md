# Go2 任务提示词示例

这些示例用于已经连接 Nuwax Embodied Harness（NEH，具身运行框架） 的上层智能体。Go2（宇树四足机器人）的数据、标定、地图和执行链应按任务需要配置完成。连接方法见[智能体接入](智能体接入.md)。

工具名称与参数以当前网关发现结果为准。地图流程使用 start_mapping（开始建图）、save_map（保存地图）、load_map（加载并重定位）与 end_map_session（结束地图会话）；保存和加载返回任务快照，按其中 task_id（任务标识）跟踪。示例表达任务目标，不预先假定某个模型、地图或运动功能已经就绪。

完整系统提示词见[机器人智能体提示词](机器人智能体提示词.md)。可先配置该提示词，再将下列场景作为日常用户任务。

## 通用执行约定

可将以下内容放入智能体的系统提示词或机器人任务说明中：

```text
你通过 Nuwax Embodied Harness（NEH，具身运行框架） 操作真实机器人。开始任务前，读取当前工具目录，并按实际参数结构调用。

先确认机器人、目标地图、定位以及任务所需能力的状态。使用工具给出的地点、物品和坐标，不猜测目标位置。

长任务返回后保存任务标识，按当前接口查询或等待。已受理不等于已经行动，运行中不等于已经完成。报告失败时保留具体阶段和原因。

响应丢失时先查询现有任务与相关状态；任务只保存在网关内存，重启后清空。不要因超时就重新发出相同运动操作。用户要求停止时，使用可用停止或取消入口，并核对实际停止结果。

记忆库随当前地图自动切换，加载地图会打开同名库的全部记忆；无建图功能的机型使用固定默认库。删除当前库会清空并立即重建，随后继续记录。地图、记忆、语义区域和导航结果各有适用范围：仅观察记录不是物体坐标；区域相邻不代表机器人可通过；导航到达后，现场确认需要新的观察。

连续识别由使用原因集合决定。手动开启只加入手动原因，手动关闭只移除手动原因；探索、跟随或找目标仍在使用时，识别继续运行。

报告任务结果时说明完成了什么，并引用实际任务结果、图像或观察。证据不足的内容明确保留未知。
```

## 前往命名地点并观察

```text
请检查当前地图中是否有可导航的“会议室门口”。若目标和导航条件齐备，前往该位置；到达后获取一张新图像，并简要描述门口情况。

如果有多个同名候选，先列出差异让我选择。如果没有对应地点或路线不可执行，说明原因，不自行猜坐标或开始探索。
```

适合验证命名地点查询、导航任务和到点观察的完整流程。

## 在限定区域内探索

```text
请在当前地图中已明确的区域边界内探索，总时限 3 分钟，并在结束时保存地图。用 explore_area_v2 的 boundary_line_segments（边界线段）表达实际地图边界；没有已知边界时先说明缺项，不把半径文字当成已经生效的边界。

先检查输入和运动条件，受理后跟踪任务进度。任务结束时分别报告探索结果、停止状态和地图是否保存成功。如果一直没有可行目标，说明具体阻塞原因。
```

当需要暂停时，可以追加：

```text
请暂停当前探索，停车后保存地图和进度。确认检查点保存结果，并告诉我之后能否恢复。
```

## 寻找曾经看见的物品

```text
请在当前地图的记忆中查找“红色椅子”，列出最相关的候选、最近观察时间和空间依据。

如果有唯一且允许导航的候选，请前往它的建议观察位置，再获取新图像确认。若只有观察记录或候选无法区分，先说明还缺什么证据。现场复核失败后，按记忆核心衰减后的最新放行结果继续处理，不沿用旧的导航建议。
```

该任务依赖真实视觉与记忆模型。只查历史使用 query_semantic_memory（查询语义记忆）；授权查找并前往时使用 find_target（寻找目标），同一任务完成识别、候选解析、导航与现场复核。只有明确允许扩大探索时才使用 explore_and_find_target（探索并寻找目标）。

## 手动连续识别与记录现场

```text
请用 get_perception_runtime_status 查看连续识别的 reasons（使用原因集合），再调用 start_perception_runtime 开启手动连续识别。

我说“关闭手动识别”时，调用 stop_perception_runtime，并报告剩余使用原因。探索、跟随和找目标仍在使用时，请说明识别继续运行，不报告全部识别已停止。

需要记住场景或标点时，使用 remember_current_scene 或 tag_location，保留已有观察的同帧图像和空间依据。没有观察时先拍照或识别；仅按当前位姿标点时说明没有附图。
```

start_perception_runtime（开启手动识别）和 stop_perception_runtime（关闭手动识别）都不接收额外开关参数。单帧拍照使用 capture_image（拍照）；场景分析可用 perceive_current_scene（识别当前场景）或 describe_current_scene（描述当前场景），两者都保留。

## 了解空间结构

```text
请读取当前语义地图与空间关系图，概述已知区域、连接关系和待确认的名称。获取带编号的地图图像后，将文字说明与图像编号对应起来。

只做查询和说明。候选标签保持候选状态，区域连接不解释为已经验证的可通行路线。
```

适用于已启用实验语义地图的环境。区域用途判断仍取决于实际观察证据。

## 导航、暂停探索与跨层

```text
导航到当前地图的指定坐标时，调用 navigate_to_pose，只给 x、y 及确实知道的高度、朝向。任务被新命令替换或急停时，按已取消报告，不声称到达。
按地名导航使用 navigate_to_place 的 query_text；先依当前地图地理参考完成换算，缺少地理参考时说明原因。
要停下并保留探索成果，调用 pause_exploration，并跟随原任务直到它返回 checkpoint_id。以后用 resume_exploration 加载、重定位和恢复进度。
跨层调用 navigate_to_floor，逐层探索调用 explore_building。它们没有断点恢复接口；中断后根据人确认的位置重新下达命令。
```
