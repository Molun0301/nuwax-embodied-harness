# 安全与数据说明

本页说明 Nuwax Embodied Harness（NEH，具身运行框架）的实际访问与数据边界，供设备接入和部署时使用。

## 网关访问

宿主机网关当前没有完整的用户登录、账号权限和令牌身份认证。能力公开标记控制工具暴露，不等于用户鉴权。网页和工具接口能发起机器人任务，不能把可访问网关的网络视为只读监控网络。

全新模块安装默认监听本机 `127.0.0.1`；已有配置继续沿用，旧配置可能监听所有网络接口。真实监听值以当前方案和进程为准。

从开发电脑访问远程主机，优先使用已有的 SSH（安全远程连接）通道。以下是模板，`robot-host` 应是已经配置的连接别名：

```bash
ssh -N -L 8766:127.0.0.1:8766 robot-host
```

保持该终端连接，在开发电脑打开 [控制台](http://127.0.0.1:8766/console)，客户端也使用该本机地址。远程网关仍可只监听自身回环地址。

需要局域网直连或代理访问时，按实际网络修改监听地址，并在网关外提供认证和访问范围控制。不要直接把8766端口暴露到公网。代理需支持长连接、数据流及下载；同时将 `NUWAX_GATEWAY_PUBLIC_BASE_URL` 设置为调用者可达的地址。

容器中的 `127.0.0.1` 指容器自己。容器接入需要显式配置宿主机可达地址和网络边界，不能只复制本机示例。NEH 不会自动替你配置组织级身份管理。

## 数据存在哪里

| 内容 | 常见位置 | 管理建议 |
| --- | --- | --- |
| 当前机器人方案 | `drivers/<机器人>/configs/` | 含设备信息或密钥，按私有配置保存 |
| 安装产物、配置和记录 | `runtime_data/installation/` 或自选目录 | 用安装器管理；不要在代际目录内存业务数据 |
| 地图资产 | `runtime_data/maps/` 及实际地图配置目录 | 保存完整地图、检查点和关联文件 |
| 模型 | `runtime_data/models/` 或自定义路径 | 明确模型来源、版本和使用许可 |
| 日志 | `runtime_data/logs/` 或配置路径 | 定期按容量策略维护，导出前脱敏 |
| 记忆数据库与图像制品 | 由当前配置指定 | 与地图关系、文件引用一起保留 |

这些是常见位置，升级或迁移前应根据实际配置查找。移除安装模块不会删除地图、模型和业务数据。系统服务部署可能使用 `/etc/nuwax/`、`/var/lib/nuwax_robot_bridge/` 等旧标识目录，产品改名不自动迁移它们。

## 何时会访问外部服务

安装需要下载系统包、Python包、所选上游源码与模型。基础网关不要求下载本地视觉或语义模型；选择对应模块后才准备其依赖。

运行时是否把图像、文本或场景信息传给外部模型，取决于所选的感知、向量化和场景决策后端。配置远程服务前，确认数据许可、服务地址和密钥保管；本地后端也需要核对模型实际缓存和依赖行为。不能因为部署在本机就默认所有处理都完全离线。

## 真实机器人运行

接入方负责真实标定、机体参数、执行器、独立停止方法和场地验证。软件运动守卫用于统一仲裁与停止，不构成硬件急停或功能安全认证。

先验证无运动的数据接入，再验证速度、停止及故障行为，最后执行导航等复合任务。上层智能体应查询实际状态、遵循能力参数和任务回执，不能用语言推断代替定位、通行或停止结果。

## 报告安全问题

当前仓库私有，使用双方已有的私有沟通渠道联系维护者，先提供影响概述与脱敏复现信息。没有约定接收方式前，不公开密钥或可利用细节。本项目尚未发布独立的漏洞响应时限或长期支持承诺。
